# plan: M2 夢の改ざん（PC の画面）と予言者の依頼

## 目的
神（プレイヤー）が PC の画面で夢を改ざんし、神託を下してドグマを生み出せるようにする。環境が悪くなると予言者が依頼（祈り）を出し、介入のきっかけを作る（[ロードマップ](../docs/roadmap.md) の M2）。仕様は [dream-tampering.md](../docs/domain/dream-tampering.md) と [prophet-request.md](../docs/domain/prophet-request.md)。

## スコープ
- 含む
  - コア: 夢の生成、改ざん、神託、100 年ごとの夢、依頼（困りごとの判定・優先・50 年あける）
  - PC の画面: 地表の下の帯に夢の 3 コマ・手札・「神託を下す」、予言者の上に依頼の吹き出し
  - 起動時の「初期の夢の改ざん」（仮の仕組み）をやめ、プレイヤーの操作に置き換える
- 含まない
  - スマホからの改ざんと依頼の表示（次の作業。メッセージもそのときに決める）
  - 崩壊しやすさの調整、依頼に応えなかったときの罰、予言者以外の NPC

## 決定事項
| 決定 | 理由 | ADR化 |
| :--- | :--- | :--- |
| 夢 3 コマ・記号 4 種類・重み 0.3〜1.0・手札 4 種類・改ざん 1 回・神託ですぐドグマ・ドグマの上限なし・100 年ごとの夢 | 人間が決めた（2026-10-12） | しない |
| 依頼の困りごと 5 つと閾値、優先の順、依頼で新しい夢、同時に 1 つ、神託で済む、同じ困りごとは 50 年あける、応えなくても何も起きない | 人間が決めた（2026-10-12） | しない |
| **AI の案**: 神託を下していない夢があるあいだは、新しい夢を見ない（100 年たっても、依頼が出ても、その夢を使う） | 改ざんの途中の夢が、急に消えないようにする | しない |
| **AI の案**: 100 年は「前の神託（起動時・リセット時からはその時点）から」数える | 夢を放っておいた後に、神託した直後に次の夢が出るのを避ける | しない |
| **AI の案**: 改ざんする前でも神託を下せる（夢をそのまま神託にする） | 夢が気に入れば、そのまま下せる | しない |
| **AI の案**: 困りごとに示す記号は、渇き・暑さ → 恵みの雨、飢え・混乱 → 木、寒さ → 聖なる火 | 吹き出しの例（「雨をお恵みください」）に合わせた | しない |
| **AI の案**: 依頼を出した後で困りごとが当てはまらなくなっても、依頼は神託を下すまで残る | 依頼の数を 1 つに保ち、仕組みを簡単にする | しない |
| **AI の案**: 依頼の判定は、時間が進んだ後（自動進行の 1 年ごと、100 年跳躍の後）の状態で行い、跳躍の途中の年では見ない | 跳躍はコアで一度に計算している（`WorldSimulator.SimulateTimeSkip`） | しない |
| **AI の案**: 依頼の吹き出しは HUD に置く（スマホの映像には映らない）。スマホには、改ざんを載せるときに別に出す | 映像は「HUD を含まない世界の描画」と決めている | しない |
| 自動進行中に新しい夢か依頼が出たら自動進行を止め、神託で再開する（夢で止めたときだけ）。夢のあいだも時間のボタンは押せる。夢の欄の 1 段目に状態の案内を出し、コマを選んでいるあいだは 2 段目を手札と「やめる」に替える | 人間が決めた（2026-10-12、手動テストの後）。状態が分かりにくく、自動進行中にコマが選べないことがあったため | しない |
| 夢のコマのボタンは作り直さずに使い回す | 押してから離すまでのあいだに時間が進むと、作り直したボタンでクリックが消えていた | しない |
| 乱数のシードは起動時に `TimeProvider` の現在時刻から作り、`event=game_started seed=...` で記録する。世界再創生では作り直さず、同じ乱数を使い続ける | `project.md` 3章（乱数はシード付き、時刻は `TimeProvider`）。記録したシードで同じ夢を再現できる | しない |
| 夢の状態（夢・改ざんしたか・依頼・待つ年数）はコアの新しいクラス `ProphetDreams` に置く。夢の状態と依頼の状態の遷移は、それぞれコードの表にする | 仕様書の状態遷移表と 1 対 1 にする（`project.md` 4章） | しない |
| 夢と依頼の調整値は `game/data/rules.json` の `dream`・`prophetRequests` に置く。`WorldMetric` に `ChaosLevel` を足す | 調整値を直書きしない。依頼の条件は地表の判定（`TerrainAnomaly`）と同じ形（指標・比較・閾値）にする | しない |
| 画面は、ノードではない C# のクラス `DreamView` にし、`WorldCore` が作る | `AmbienceView` と同じ置き方 | しない |
| 時間の進め方の仕様書の「初期の夢の改ざん」をやめる。使わなくなった `TimeControl` の初期のドグマの引数を消し、リセットではドグマの一覧を空にする。テストはリセットの 2 件（TS-time-control-004・007）の期待値を「ドグマが空」に変える | 仮の仕組みを、プレイヤーの操作に置き換える。承認された仕様変更に合わせた期待値の修正（`project.md` 3章） | しない |

## 処理の流れ

### 起動時（`WorldCore._Ready`）
- `TimeProvider.System` の現在時刻からシードを作り、`new Random(seed)` を作る。`event=game_started seed=...` を記録する。
- `TimeControl` を作る（ドグマの一覧は空）。
- `ProphetDreams` を作り、`Begin(世界)` を呼ぶ → 夢を見る（`event=dream_created dreamNodes=...`）。
- `DreamView` を作り、夢の欄を描く。

### 夢を見る（`ProphetDreams` の中）
- 神託を下していない夢があれば、何もしない。
- `DreamGenerator.Generate(乱数, 定義)`: 夢ノードを 3 つ作る。記号は使う記号の一覧から、重みは 0.3〜1.0 から、乱数で選ぶ。
- 状態を「改ざん前」にする。

### 時間が進んだ後（`WorldScreen` が、100 年跳躍の後と、自動進行の 1 年ごとに `ProphetDreams.OnTimeAdvanced(世界)` を呼ぶ）
- 星が崩壊していれば、何もしない。
- 依頼なしなら、困りごとの表を優先の順に見て、当てはまり、かつ待つ年数の中でない最初のものを依頼にする（`event=prophet_prayed year=... requestType=...`）。依頼を出したら、夢を見る。
- 依頼を出さなかったときは、前の神託（か起動・リセット）から 100 年以上たっていれば、夢を見る。
- 結果（新しい夢を見たか、依頼を出したか）を返し、`DreamView` が描き直す。

### 改ざん（PC の画面で夢のコマを押し、手札のカードを選ぶ）
- 崩壊している、夢なし、改ざん済みのどれかなら不可（ボタンは無効表示。コアは例外を投げる）。
- 範囲外のコアの位置、使う記号に無い記号 ID も例外にする。
- 夢ノードの記号を替え、重みはそのまま。状態を「改ざん済み」にする（`event=dream_tampered dreamNodes=...`）。

### 神託を下す（「神託を下す」ボタン）
- 崩壊している、夢なしなら不可。
- `DreamInterpreter.Interpret(夢, 定義)` でドグマを作る。ドグマがあれば `TimeControl.AddDogma` で一覧に加える（`event=dogma_formed ...`）。
- 夢を消し、状態を「夢なし」にし、前の神託の年を今の年にする。
- 依頼中なら依頼なしにし、その困りごとの待つ年数を今の年から始める（`event=prayer_answered requestType=...`）。
- `WorldScreen` が HUD のドグマの一覧を描き直す。

### 世界再創生
- `TimeControl.Reset()` の後に `ProphetDreams.Reset(世界)`: 夢・依頼・待つ年数を消し、前の神託の年を 0 にして、夢を見る。

### PC の画面（`DreamView`）
- 地表の下の帯に、夢のコマ 3 つ（記号の名前のボタン）と「神託を下す」ボタンを並べる。コマを押すと、その上に手札 4 枚のボタンを出す。
- 夢なしのときは、コマの代わりに「予言者は眠っている」と出す。
- 依頼中は、予言者の上に吹き出し（`{困りごと}に苦しんでいます。{記号}をお恵みください`）を出す。
- 崩壊中・改ざん済み・夢なしのときは、押せないボタンを無効表示にする。
- 文言は `game/locales/ui.csv` に足す。
