# 画面の割り付けを作り直す（MVP の見た目の段 1）

## 目的
MVP の範囲を決め直した（[ロードマップ](../docs/roadmap.md)の「MVP の範囲を決め直す」）。今は 480 × 336 px の 1 枚の画面に地図と文字を同じ粗さで描き、地図は左上の 4 分の 1 ほどしかなく、右のボタンの列と下の欄が場所を取っている。地図を主役にし、文字はにじまない解像度で描く（[アセットと画面の規格](../docs/art-guide.md)の「見た目の作り直し」の 1〜3）。色と絵の描き直し（4・5）は次の段で行う。

## スコープ
- 変える: `project.godot` の画面の設定、`main.tscn` の HUD の木、HUD を作る各ビュー（`WorldScreen`・`DreamView`・`OracleView`・`NotebookView`・`HistoryView`・`ResidentView`・`CarvingView`・`ScriptComposerView`・`CompanionHost` の QR とアドレス・`WorldCore` のセーブの知らせ）の置き場所、テーマの文字の大きさ、`rules.json` の `camera.startZoom`。
- 新しく作る: 上の帯（年と世界の値のアイコン）、右上の操作、メニュー、左下の出来事の行、下の帯、左右の引き出し。
- 変えない: コア（`src/`）、セーブ、通信、スマホへ送る画面（480 × 270 px のまま）、地表・人・家・印の絵と色。
- 範囲の外: パレットと絵の描き直し（次の段）、スマホの画面、地層の画面の作り直し（MVP の外。メニューから開けるまま残す）。

## 決定事項
下は AI の推奨。人間が直す所があれば直す。

| 決定 | 理由 | ADR化 |
| :--- | :--- | :--- |
| 文字と操作は 960 × 540 を基準に描き、窓の大きさに合わせて小数倍でも拡大する（`stretch/mode = canvas_items`、`aspect = expand`）。文字は実際の画面の解像度で描くのでにじまない | 地図と文字の解像度を分ける（art-guide の 1）。16:9 の窓で黒い帯を出さない | 不要 |
| 地図は今の 480 × 270 px の `SubViewport` のまま、画面のピクセルで整数倍になる倍率で画面いっぱいに出す。窓を覆う最小の整数倍にし、はみ出す端は切る（1920 × 1080 なら 4 倍でちょうど） | ドットの幅をそろえたまま、黒い帯を出さない。スマホへ送る画面も変わらない | 不要 |
| 起動時のズームを 0.5 倍から 1 倍にする（`camera.startZoom`） | 地図が画面いっぱいになるので、1 倍で地表のほぼ全体が映る。0.5 倍では画面の半分しか使わない | 不要 |
| 上の帯（高さ 24 ほど、半透明）: 左に年、続けて世界の 5 つの値（森・水・気温・カオス・調和）を小さなアイコンと短い目盛りで出す。数値はアイコンに乗せたときの説明（ツールチップ）に出す | 文字の羅列をやめ、地図を覆わない（art-guide の 2）。アイコンは今は単色の仮の絵で、次の段で描く | 不要 |
| 右上: 自動進行と一時停止を 1 つのボタンで切り替え、速さ、100 年跳躍、メニュー（☰）を並べる。自動進行中の次の年までの残りは、年の横に出す（実装で、説明に隠すより今の仕様どおり見えるほうがよいと判断した） | よく押すものだけを残す。切り替えの決まり（time-control.md の状態遷移表）は変えない | 不要 |
| メニューに入れるもの: 世界再創生・全セッションリセット・地上と地層の切り替え・スマホをつなぐ QR とアドレス | めったに押さないもの、MVP の外のもの。星が崩壊したら ☰ を赤く点滅させ、開いた中の世界再創生も点滅させる | 不要 |
| 下の帯（高さ 32 ほど、半透明）: 左に神威、中央に「文を書く」、右に「手帳」「年表」。案内の文（「手帳の字で文を書き、語りかけよ」）は「文を書く」の説明に移す | 主な操作を 1 本にまとめる（art-guide の 2） | 不要 |
| 左下の出来事の行: 年表に新しく載った行を、下の帯のすぐ上に新しいものから 3 行まで出し、数秒で薄れて消える。セーブの知らせもここに出す | 起きたことに気付けるようにする（art-guide の 2）。年表の文（`ChronicleText`）を使い回す | 不要 |
| 手帳は右、年表は左の引き出しにする。開いている間だけ、上下の帯の間に地図に重ねて出す。今の教え（ドグマの一覧と信者の数）は年表の引き出しの頭に移す | 地図を覆うのは開いている間だけにする（art-guide の 3） | 不要 |
| 字を組む欄は、下の帯の上に出す下からの板にする。碑の拓本は画面の中央の板、住人の札は左上（上の帯の下）にする | 引き出しと重ならない置き場所を決める | 不要 |
| 依頼の吹き出し・祈りの字・神託の吹き出しは、予言者の頭の上に付けて動かす | 今は依頼の吹き出しだけが予言者に付き、祈りの字と神託は画面の決まった所に出て地図の真ん中を覆う | 不要 |

## 処理の流れ
1. 起動: 窓の大きさから地図の倍率を決める。倍率 = 窓を覆う最小の整数（`ceil(max(窓の幅 / 480, 窓の高さ / 270))`、最小 1）。地図の `SubViewportContainer` をその倍率で中央に置き、はみ出しは切る。窓の大きさが変わったら決め直す。
   - 文字の拡大（`canvas_items`）と地図の倍率が掛け合わさるので、地図の側では文字の拡大の分を打ち消して、画面のピクセルで整数倍にする。打ち消し方は Godot で動かして確かめる。うまくいかなければ止めて報告する。
2. 時間が進んだとき: 上の帯の年・5 つの値の目盛り・説明の数値を描き直す。ボタンの押せる・押せないは今と同じ表（`TimeControl.CanDo`）で決める。
3. 年表に行が増えたとき: 増えた行を出来事の行に足す。3 行を超えたら古い行から消す。各行は数秒で薄れて消える。跳躍で一度に多く増えたときは、新しい 3 行だけを出す。
4. 「手帳」「年表」を押したとき: その引き出しを開く。もう一度押すと閉じる（地図のクリックはドラッグと住人・碑を選ぶのに使うので、閉じるのには使わない。実装で変えた）。手帳と年表は同時に開ける（左右に分かれているため）。
5. 「文を書く」を押したとき: 字を組む板を開く。開いている間は引き出しを閉じる（今の字を組む欄は手帳の字を使うので、手帳は開いたままにする）。
6. 地図の上のドラッグ・ホイール・クリックは、帯・引き出し・板の上では地図に届けない（今の HUD のボタンと同じ扱い）。
7. 星が崩壊したとき: ☰ を赤く点滅させる。メニューを開くと、世界再創生のボタンも点滅させる。

## テスト観点
- 自動テスト: コアを変えないので、新しいテストは足さない。`sh scripts/check.sh` が通ること。
- Godot で動かして確かめる（画面写真を撮る）:
  - 窓が 1920 × 1080・1280 × 720・1440 × 1008 で、地図が画面いっぱいに出て、ドットの幅がそろい、文字がにじまない。
  - 上の帯の年と目盛りが時間とともに変わり、説明に数値が出る。
  - 自動進行・一時停止・速さ・跳躍・メニューの中の操作が今と同じに動く。崩壊で ☰ が点滅する。
  - 手帳・年表の引き出し、字を組む板、碑の拓本、住人の札が重ならずに開く。
  - 祈りの字と依頼の吹き出しが予言者に付いて動く。出来事の行が出て消える。
  - スマホへ送る画面が 480 × 270 px のまま（ログの大きさで確かめる）。
- 仕様書とテスト仕様書: HUD の書き方（planet-display.md の「HUD」・camera-views.md の起動時のズームと AC-camera-views-006・art-guide.md の「画面」の表）を今の姿に書き換え、関係する手動テストの行を直す。
