時間進捗（タイムスケール）の4モード案
リアルタイムモード（1秒＝1秒 / 1年＝現実の1年または1日）

現実同期（1年＝現実の1日 / 24時間）:

現実の24時間でゲーム内の1年が進むモード。朝起きてスマホや画面を見ると「1年経って環境がわずかに変化している」「予言者が新しい夢を見た」という通知が来る、まさに生活に寄り添うアクアリウム体験。

完全リアルタイム（1秒＝1秒）:

予言者の呼吸、焚き火のゆらめき、人間たちの1日の生活サイクル（朝〜夜）が現実時間と100%同期するモード。

じっくり観察モード（1秒＝1か月 ➔ 12秒で1年）

人間の動きや環境の変化（緑が少しずつ枯れて砂漠化していく様子）が目で追えるスピード。コーヒーを飲みながら放置して眺めるのに最適です。

歴史加速モード（1秒＝1年）

今検討していた「1秒で1年進む」標準的なスピード。文明の興亡や気候変動が数分単位で劇的に展開します。

神意跳躍（ボタン一発で100年）

夢の改ざんを行った直後など、「この結果をすぐに確かめたい！」という検証・開発テスト用の瞬間スキップ。

実装・仕様としてのアイデア
Godot側での実装も、時間の倍率（TimeScale）をかけるだけなので非常にシンプルに組めます。

C#
public enum TimeMode
{
    RealTime,   // 1年 = 現実の24時間（または1年=1時間）
    Slow,       // 12秒 = 1年（じっくり観察）
    Normal,     // 1秒 = 1年（標準進捗）
    Fast        // 1秒 = 10年（高速スキップ）
}

// 1年が進むのに必要な秒数（Delta timeで管理）
private float GetSecondsPerYear(TimeMode mode) => mode switch
{
    TimeMode.RealTime => 86400.0f, // 現実の1日(24h)で1年進む
    TimeMode.Slow     => 12.0f,    // 12秒で1年
    TimeMode.Normal   => 1.0f,     // 1秒で1年
    TimeMode.Fast     => 0.1f,     // 0.1秒で1年
    _ => 1.0f
};
