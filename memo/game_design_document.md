# ゲーム企画書：『予言者の歪んだ夢（仮）』

**〜 多重誤解（ダブル・ブラインド）ミステリー・シミュレーター 〜**

---

## 1. コアコンセプト ＆ 裏テーマ

### コアコンセプト
神（プレイヤー）と人間（NPC）の双方が互いの言葉や意図を理解できない**「多重誤解（ダブル・ブラインド）」**の状態で展開する2D地球環境＆歴史シミュレーション。

プレイヤーは直接的な天変地異で世界をねじ伏せるのではなく、**時代ごとに1人だけ現れる「予言者（受容体）」の夢の1コマをすり替える（大介入）**ことと、**人間側からの問いかけ（神啓）に限定された記号で返答する**ことで歴史を導く。予言者の歪んだ解釈から生まれた教義（ドグマ）が集団の行動を偏らせ、数百年かけて地球全体の気候・地殻・生態系を激変させていく。

### 裏テーマ：『カオスと調和の天秤』
* **カオス（混迷・破壊）:** 人間の愚かな誤解、狂信、急激な環境破壊、戦争、奇祭。新しい「象徴記号（言葉）」や「ひらめき」を生み出す種となる。
* **調和（秩序・箱庭）:** 聖典によるルール固定、穏やかな信仰、美しい景観、持続可能なエコシステム。プレイヤーに癒やしと「神徳（微調整リソース）」をもたらす。
* **体験の本質:** カオスな誤解を面白がりつつ、ギリギリのところで手綱を引いて自分好みの美しい調和（箱庭都市）へと収束・維持させる**「神の葛藤と愛で」**をプレイする。

## 2. 基本ルール ＆ 境界条件

* **制限なし（No Taboos）:**
  商業的なレイティングや規制を考慮せず、人間の泥臭い愛憎、狂信、生贄、自己解体、極限の環境破壊などをそのままシミュレーションの要素として組み込む（トグルでのマイルド化フィルターも完備）。
* **絶対的な終了条件：『星の物理的崩壊・消滅』**
  宇宙開発などへは進まず、あくまで**「1つの星（アクアリウム）」**の閉鎖空間に密度のすべてを凝縮。星が木端微塵に砕け散るか、完全な死の無の星になるまでは、何世代全滅しようが何百年でも好き勝手に遊び続けることができる。

## 3. ゲームループ（2層構造タイムスケール）

```
【1. ミクロ観察 ＆ 解読フェーズ（1日単位）】
  ・受容体（予言者）の日常や集落の様子を観察。
  ・未知の象徴記号（👁️ 💧 🌲 等）と彼らの行動パターンから言語（辞書）を解読・推理。
       ↓
【2. 夢の改ざん ＆ 問解応答（介入フェーズ）】
  ・［大介入］予言者の就寝時、夢の1コマ（タイムライン）をカードスワップして大事故の種を蒔く。
  ・［問解応答］人間側から「神啓（問い合わせ）」が届いた際、象徴カード1〜2枚で返答。
       ↓
【3. リアルタイム経過 ＆ 微調整（フィードバック・コントロール）】
  ・教義（ドグマ）が広まる様子を観察。
  ・「予言者の耳鳴り（閃き）」や「不吉な兆候（局所天候）」で過激な暴走にブレーキ／アクセルをかける。
       ↓
【4. マクロ跳躍フェーズ（50〜300年一括ジャンプ）】
  ・予言者の誤解が宗教（ドグマ）として硬化し、地球環境が激変していく年代記を観測。
  ・崩壊した文明の地層の上に生まれた「新時代（次の受容体）」へ切り替わる。
```

## 4. 時代推移 ＆ 特殊イベント・バリエーション

### 時代（Epoch）の段階推移
原始時代の小さな焚き火の集落から始まり、人間のドグマと環境パラメータの閾値突破によって地続きに時代が遷移する。

1. **【第1紀：原始・古代】** 石器、火の発見、初期の精霊信仰、狩猟採集
2. **【第2紀：中世・王国】** 鉄器、大都市の建設、組織的宗教、戦争
3. **【第3紀：近代・産業】** 蒸気・機械化、大規模公害、環境汚染
4. **【第4紀：現代・未来】** 自動化、AI信仰、地殻開発、気候操作
5. **【第5紀：超越・終末】** 精神体化、生体・粘菌都市、地球自転停止、全球凍結地底文明

### ランダム・レイヤー交差イベント
* **天外イベント（隕石・宇宙人）:**
  突然の隕石降下（クレーター・気候冷え込み）や、宇宙人の飛来（異種テクノロジーの置き土産・テラフォーミング等）という外部の理不尽に対し、人間たちが独自の誤解（ドグマ）で立ち向かう。
* **時代・レイヤー交差（太古の地底人 × 後の地表人）:**
  太古の破滅を逃れて地底へ潜った「地底人（旧人類）」と、数万年後の地表で生まれた「地表人（新人類）」が接触。言語が通じない中での「三重の誤解（トリプル・ブラインド）」が発生し、大規模な聖戦または美しい「二層都市（縦穴回廊）」へと発展する。

## 5. マルチデバイス構成（PC × スマホ）

PCとスマホがリアルタイムで連動する**「神のデュアル画面体験」**を採用（WebSockets / PWA技術による専用アプリ不要のWeb接続）。

```
【PC（ホスト / 鑑賞・描画・計算エンジン）】
  ・高解像度2Dドット絵×2.5Dライティングの地球・断面マップ鑑賞画面。
  ・大容量物理・気候・NPC思考シミュレーションの実行。

【スマホ（Companion App / 神意通信端末）】
  ・ポケットの中で鳴る通知：「予言者が就寝しました」「神啓（問解）が届いています」
  ・手元のフリック＆タップで「夢改ざん」「問解への返答」を実行。
  ・地球の崩壊度（マグマ圧・気温）やカオス／調和メーターの常時監視。
```

## 6. アーキテクチャ ＆ 処理分担（CPU vs GPU）

PCのスペックをフルに活用し、**「カメラ付近の数百人は高解像度ドットアニメ＋深層思考」「背景・地球全体は数万人規模の並列計算」**を両立する。

```
【CPUの担当（ロジック・シリアル処理）】
  ・ゲーム全体の進行管理、イベントフラグ判定
  ・スマホ（Web）との通信受付、予言者個人の複雑な感情・テキスト分岐

【GPUの担当（GPGPU / Compute Shader並列計算）】
  ・数万人のNPCの「移動（経路探索）・群衆の衝突回避」
  ・数万人分の「教義（ドグマ）の伝播・感染確率計算」
  ・地球全体の格子（16x16〜256x256）における大気・気候・マグマの流体計算
  ・全ドット絵NPCの「GPU Instancing」による一括描画
```

## 7. 鑑賞・カスタマイズ要素（箱庭アクアリウム）

* **ドグマによるビジュアル動的置換:**
  「水・清らか・建築」などのドグマへ誘導した結果、人間の建築・衣装・生活様式が美しい「白い水上都市」へと自動で染まっていく着せ替え感覚。
* **聖典（ゴールド・ドグマ）の固定:**
  お気に入りの美しい教義ができた際、羊皮紙に固定して数百年後の時代へも受け継がせ、全滅を防ぐガードレールにする。
* **アクアリウムモード:**
  UIを非表示にし、朝・昼・夕・夜の光の変化と環境音（雨の音、街の喧騒、せせらぎ）を聴きながら心ゆくまで箱庭都市を眺めて癒やされる。
