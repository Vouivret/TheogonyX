## 手動テストの手順

### TS-oracle-speak-ui-001
1. メインシーンを実行し、自動進行で数年進めて住人が移り住むのを待つ。入力欄に「森を守れ」と書き、「語りかける」を押す。
2. 予言者の吹き出しに「予言者は耳を澄ませている…」が出て、自動進行が止まることを確かめる。
3. 数秒後に、吹き出しの頭に「〈木〉を崇めよ」の形の掟の 1 行（聞き違えがあれば別の記号・種別）と、聞こえた言葉が出て、自動進行が再開することを確かめる。続けて LLM の聞こえた文と語りに差し替わる。
4. HUD の教えの一覧に、教えと信者の人数が出ること、神威が 1 減ることを確かめる。「東へ旅立て」のように行き先を書くと、予言者の絵が東へ動くことを確かめる。
5. 手札に無い記号の言葉（例: 手札に無い「火」）を書いたとき、近い知っている言葉に聞き違えることを確かめる。

### TS-oracle-speak-ui-002
1. Ollama を止めて起動する（または `rules.json` の `oracleAi.enabled` を false にする）。入力欄の代わりに、名詞・動詞・行き先の選ぶ欄が出ることを確かめる。
2. 名詞と動詞を選んで「語りかける」を押し、掟の 1 行と聞こえた言葉が出ることを確かめる。
3. Ollama が動いているときに、LLM が途中で失敗した場合は、書いた文を残したまま選ぶ欄に替わることを確かめる（Ollama を途中で止める）。

### TS-oracle-speak-ui-003
1. 「方言帳」のボタンを押し、聞き違えた語が「神の言葉 → 予言者に聞こえた言葉（理由）」の形で新しい順に出ることを確かめる。謎の言葉（一覧に無い言葉）は「謎の言葉」として出る。

### TS-oracle-speak-ui-004
1. 古いセーブが `world.old-<日時>.json` に名前を変えて残り、新しい星で始まり、「前の星は新しい版では読めないので残して…」が 10 秒出ることを確かめる。
