## 手動テストの手順

### TS-ambience-006
1. Godot 4.7.2（.NET 版）で `game/project.godot` を開き、F5 でメインシーンを実行する。
2. 予言者が地表の左から 16 列目の上に立ち、足元が地表の上端に接していることを確かめる。
3. 予言者のコマが 0.5 秒ごとに変わり、ループすることを確かめる。
4. 地表と予言者の色が、およそ 12 秒で 青空 → 夕焼け → 夜 → 朝 → 青空 と滑らかに変わること、HUD の色は変わらないことを確かめる。
5. 星を崩壊させ、環境光が赤黒で止まり、予言者が倒れた姿になることを確かめる（崩壊を起こせる手段ができるまでは未実施でよい。[実施記録](results/2026-10-11-feat-m1-screen.md) の TS-time-control-009 と同じ理由）。
6. リセットを押し、予言者が立った姿に戻り、色の移り変わりが止まったところから続くことを確かめる。
7. 出力パネルにエラー・警告が無いことを確かめる。

## 対象外

- 周期の秒数の正確さ（フレームレートによる誤差）: 「およそ」で確かめる。
- 本番の予言者の絵: 届いたときに手順 2・3 を確かめ直す。
