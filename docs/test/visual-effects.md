## 手動テストの手順

### TS-visual-effects-006
1. Godot 4.7.2（.NET 版）で `game/project.godot` を開き、F5 でメインシーンを実行する。
2. 予言者の左（地表の左から 12 列目の上）に薪があり、足元が地表の上端に接していることを確かめる。
3. 青空のあいだは炎も明かりも無く、夕焼けから炎と明かりが灯り、夜にいちばん明るくなり、朝に消えることを確かめる（12 秒で 1 周）。
4. 灯っているあいだ、明かりが揺らぐことを確かめる。
5. 星を崩壊させ、炎と明かりが消えて薪だけが残ることを確かめる。リセットを押し、夜になるとまた灯ることを確かめる。
6. 出力パネルにエラー・警告が無いことを確かめる。

### TS-visual-effects-007
1. Godot 4.7.2（.NET 版）で `game/project.godot` を開き、F5 でメインシーンを実行する。建物が無ければ、100年跳躍を何度か押して建てる。
2. マウスホイールで 2 倍に拡大し、予言者と建物を見る。
3. 昼（青空）のあいだ、予言者と建物の絵の左上の縁が明るく、右下の縁が暗いことを確かめる。地表・群衆・焚き火には陰影が無いことを確かめる。
4. 夜になったとき、予言者と建物だけが周りより明るく浮いていないことを確かめる。
5. 予言者と建物の足元に、半透明の黒い楕円の影があり、絵の後ろに描かれ、下半分が絵からはみ出していることを確かめる。
6. 星を崩壊させ、倒れた予言者の足元にも影があることを確かめる。
7. 出力パネルにエラー・警告が無いことを確かめる。

### TS-visual-effects-008
1. Godot 4.7.2（.NET 版）で `game/project.godot` を開き、F5 でメインシーンを実行する。
2. マウスホイールで引いて、地表の外の空が見えるようにする。
3. 12 秒の周期の中で、空の色が昼の灰色 → 夕焼けの赤み → 夜の暗さ → 朝 と変わること、夕焼けから星が出て夜にいちばん濃く瞬き、朝に消えることを確かめる。
4. いちばん引いたズーム（0.25 倍）でも、空の端が見えないことを確かめる。
5. 星が地表・予言者・建物の上に出ないことを確かめる。
6. 夢の改ざんで星を崩壊させ、星が出ないことを確かめる。

## 対象外

- 焚き火・法線マップの陰影・落ち影以外の効果（ポストプロセス・水と大気・粒子）: 値が決まってから足す。
