# アセットと画面の規格

ドット絵のアセットと、Godot の画面設定の規格。アセットを作る・取り込むときはこれに合わせる。取り込んだアセットの出典とライセンスは [credits.md](credits.md) に記録する。

出典: `memo/asset.md` の案を、2026-10-11 のチャットで確定。

## 見た目の作り直し（2026-11-09 の方向）

2026-11-09 に人間が「見た目は全体が気になる」と言い、AI の推奨で方向を決めた。1〜3 は同じ日に作り、4 は 2026-11-10 に作った（下の「画面」、[plan](../plan/feat-layout-rebuild.md)）（[ロードマップ](roadmap.md)の「MVP の範囲を決め直す」）。下の規格と食い違うところは、作り直す段で規格を書き換える。細かい値（解像度・パレットの色・フォント）は、作り直す段の plan で決める。

1. **地図と文字の解像度を分ける**: 今は 480 × 336 px の 1 枚の画面に、ドット絵と文字を同じ粗さで描いているので、文字が地図を覆う。地図（地表・建物・人・印）だけを低い解像度で描いて整数倍に拡大し、文字と操作は高い解像度で描く。
2. **地図を主役にする**: 地図を画面いっぱいに出し、ほかは地図の上に半透明で重ねる。上の細い帯に年と世界の値のアイコン、右上に一時停止・速さ・メニュー、左下に出来事を短く知らせる行、下の 1 本の帯に「神託を書く」・手帳・年表。世界の値は文字の羅列ではなく、アイコンと空・地面の色で見せる。
3. **手帳と年表は引き出しにする**: 開いている間だけ、地図の端に出す。
4. **色をそろえる**: 地表の DB16 とキャラクターの自由な色が混ざっている今の形をやめ、32 色ほどの 1 つのパレットにそろえる。
5. **絵を描き直す**: 地表・家・人・印を、同じ大きさと視点の決まり（16 px のマス、やや上から見下ろす視点）で描き直す。1〜3 で割り付けを固めてから絵に入る。

## パレット

2026-11-10 に、色を 1 つのパレットにそろえた（[plan](../plan/feat-palette-art.md)）。32 色は [`game/data/palette.json`](../game/data/palette.json) に、名前と `#RRGGBB` で置く。外部のパレットは使っていない（DB16・DB32 はライセンスの記載が確認できないため。[出典](credits.md)）。

| 系統 | 色（名前。暗い順） |
| :--- | :--- |
| 暗い灰 | `ink`・`night`・`slate`・`stone`・`ash`・`bone`・`snow` |
| 土と木 | `soil`・`bark`・`clay`・`sand`・`dune` |
| 肌 | `skin_shadow`・`skin` |
| 赤と火 | `blood`・`red`・`ember`・`flame`・`sun` |
| 緑 | `deep_forest`・`forest`・`leaf`・`grass`・`meadow` |
| 青 | `deep_sea`・`sea`・`water`・`sky`・`ice`・`lagoon` |
| 紫 | `dusk`・`magic` |

- コードは色を名前で引く（`GamePalette.Of("ember")`）。値を直書きしない。`rules.json` の色も名前で書く（環境光の昼夕夜の掛け算の色は、画面に直接出ないので `#RRGGBB` のまま）。
- 色の定義は 32 個ちょうどで、名前と値は重複できない。守られていなければ起動で失敗する。
- 絵（PNG）は、パレットのいちばん近い色に減色し（ディザなし）、半透明の画素を使わない。減色は Godot に `-- --quantize-sprites` を付けて起動する道具（`SpriteQuantizer`）で行い、終わりにパレットの外の色と半透明の画素が 0 であることをログに出す。
- 地表の外（宇宙）の色は `night`（`project.godot` の `rendering/environment/defaults/default_clear_color`）。
- UI のテーマ（`game/ui/theme/main_theme.tres`）の色はパレットの値を写している。パレットを替えたら、テーマも合わせる。
- 地表のタイルは、種類ごとに 4 通りの 16 × 16 px の模様（地の色 + 2〜3 色）をコードで描き、マスの位置で使う模様を変える（`TerrainArt`）。世界の値のアイコン（10 × 10 px）もコードで描く。

## ドット絵
| 項目 | 規格 |
| :--- | :--- |
| タイルの大きさ | 16 × 16 px |
| キャラクターのスプライトの大きさ | 予言者は 16 × 16 px（下の「予言者のスプライト」）、住人は 10 × 14 px。2026-11-10 に、予言者を 32 × 32 から縮めて住人と同じ縮尺にした |
| カラーパレット | 自前の 32 色（上の「パレット」）。地表・建物・人・印・UI のすべてがこの色だけを使う（2026-11-10 に、DB16 と「キャラクターは自由な色」の例外をやめた） |
| テクスチャのフィルタ | Nearest（ミップマップなし。`.agent/rules/godot.md`）。地図の絵（建物・住人・印）は `Actors` ノードで指定し、拡大してもぼけない |
| 絵の視点と縮尺 | 斜め上から見下ろす（建物は角が手前に来る）。1 階建ての建物は 32 × 32 px（最大の幅を 32 px に合わせ、同じ縮尺で縮める）、2 階建ては 32 × 48 px。住人は背の高さ 14 px（10 × 14 px の枠）、予言者は 16 × 16 px の枠（2026-11-10 に、新しい参考画から描き直した） |

## 予言者のスプライト

出典: 2026-10-11 のチャットで確定（[画面の演出](domain/ambience.md)）。大きさと色は、届いた絵に合わせて同日に 16 × 16・DB16 から変更した。2026-11-10 に、人間の指示（予言者を小さくする）で 32 × 32 から 16 × 16 に縮め、色をパレットにそろえた。同じ日に、絵の描き直しの小段（[plan](../plan/feat-palette-art.md) の 3b）で、開発者が生成 AI で作った参考画から切り出し直した（緑の頭巾の老人。座った姿 3 枚を `1 → 2 → 3 → 2` と往復させた 4 コマ）。

| 項目 | 規格 |
| :--- | :--- |
| ファイル形式 | PNG（RGBA 8bit、背景は透明） |
| 色 | [パレット](#パレット)の色だけ。半透明やアンチエイリアス（中間色）は使わない |
| 1コマの大きさ | 16 × 16 px。余白を含めて、全コマ同じ大きさにする |
| 待機アニメーション | `game/assets/sprites/prophet_idle.png`。2〜4 コマを左から再生順に横一列につなぐ（2コマなら 32×16、4コマなら 64×16）。コマの間に隙間を入れない。コマ数は横幅 ÷ 縦の高さで決まる |
| 倒れた姿 | `game/assets/sprites/prophet_fallen.png`。16 × 16 px の1コマ |
| 足元 | 足の一番下のドットを、絵の最下段（y = 15）に置く。地表の上端に接地させる位置合わせに使う |
| 向き | 右向き |

ファイルが無い間は、コードで作る仮の絵（単色の人形）を表示する。ファイルを置いたら Godot エディタで一度開き、読み込み（`.import`）をエディタに作らせる。

## 住人の欲求の印

出典: 2026-10-14 のチャット（[カメラの視点](domain/camera-views.md)）。

| 項目 | 規格 |
| :--- | :--- |
| ファイル（欲求） | `game/assets/sprites/icon_need_hunger.png`（空腹）・`icon_need_shelter.png`（住居）・`icon_need_sanity.png`（SAN 値。今の画面で使う 3 枚）、`icon_need_social.png`（交流）・`icon_need_esteem.png`（承認）・`icon_need_actualization.png`（自己実現）・`icon_need_health.png`（体力） |
| ファイル（状態） | `icon_state_rampage.png`（狂乱）・`icon_state_catatonia.png`（自閉・絶望）・`icon_state_dead.png`（死） |
| ファイル形式 | PNG（RGBA 8bit、背景は透明。半透明やアンチエイリアスは使わない） |
| 大きさ | 12 × 12 px（2026-10-14 に 8 × 8 から変更。王冠・電球・剣の細部が残るため） |
| 色 | 自由な色でよい |

出典: 画像生成で作った 1 枚の絵（5 × 3）から 10 個を切り出し、白い背景を透明にして 12 × 12 px に縮め、縁を 2 値（透明か不透明）にそろえた。自閉・絶望の顔だけ、左右対称に手で整えた。画面で使うのは、欲求の 3 枚（空腹・住居・SAN 値）と、状態の 2 枚（狂乱・自閉・絶望）。交流・承認・自己実現・体力・死は置いてあるだけ。ファイルが無いときは、コードで作る単色の仮の絵（橙・茶・紫）を表示する。ファイルを置いたら Godot エディタで一度開き、`.import` を作る。

## 画面（`project.godot`）
| 設定 | 値 |
| :--- | :--- |
| ビューポートの幅（`display/window/size/viewport_width`） | 960（文字と操作の基準） |
| ビューポートの高さ（`display/window/size/viewport_height`） | 540 |
| 起動時の窓の大きさ（`window_width_override`・`window_height_override`） | 1440 × 810 |
| 拡大のモード（`display/window/stretch/mode`） | `canvas_items` |
| 縦横比（`display/window/stretch/aspect`） | `expand` |
| 拡大率（`display/window/stretch/scale_mode`） | `fractional`（既定。小数倍も使う） |
| 地図（`WorldViewport`） | 480 × 270 px。画面のピクセルで整数倍になる倍率で、窓を覆うように置く（`HudLayout`） |

2026-11-09 に、地図と文字の解像度を分けた（[plan](../plan/feat-layout-rebuild.md)）。
- 文字と操作は 960 × 540 を基準に、窓に合わせて小数倍でも拡大する。文字は実際の画面の解像度で描くので、にじまない。黒い帯は出さない。
- 地図は、窓を覆う最小の整数倍（`ceil(max(窓の幅 / 480, 窓の高さ / 270))`）で中央に置き、はみ出す端は切る。文字の拡大の分は地図の側で打ち消すので、ドットの幅は画面のピクセルでそろう（1440 × 810 なら 3 倍、1920 × 1080 なら 4 倍でちょうど）。
- スマホへ送る画面（[画面の配信](domain/frame-stream.md)）は、地図の 480 × 270 px のまま。

割り付け（基準の座標で）:

| 場所 | 出すもの |
| :--- | :--- |
| 上の帯（高さ 36、半透明） | 左に年と次の年までの残り、中に世界の 5 つの値のアイコンと目盛り、右に自動進行／一時停止・速さ・100 年跳躍・メニュー（☰） |
| メニュー（☰ の下） | 世界再創生・地上と地層の切り替え・全セッションリセット・スマホの接続先と QR コード |
| 下の帯（高さ 36、半透明） | 左に神威（崩壊したときと神威が足りないときは、その案内も）、中央に「文を書く」（今の状態の案内はボタンの説明）、右に「手帳」「年表」 |
| 左下（下の帯の上） | 年表に新しく載った行を 3 行まで。6 秒で薄れて消える。セーブの知らせもここ |
| 左の引き出し（幅 300） | 今の教えと星の年表。「年表」で開け閉めする |
| 右の引き出し（幅 240） | 字の手帳。「手帳」で開け閉めする |
| 下からの板（左寄せ、幅 560） | 字を組む欄。開くと年表の引き出しを閉じる |
| 中央の板 | 碑の拓本 |
| 左上（上の帯の下） | クリックした住人の札 |
| 予言者の頭の上 | 上から神託の吹き出し・祈りの字・依頼の吹き出し |

文字の大きさは 14（出来事の行は 13、黒い縁取り）。帯・引き出し・板・吹き出しの色はテーマ（`game/ui/theme/main_theme.tres` の `HudBar`・`Drawer`・`Sheet`・`Bubble`）に置く。
