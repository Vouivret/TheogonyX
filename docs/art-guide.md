# アセットと画面の規格

ドット絵のアセットと、Godot の画面設定の規格。アセットを作る・取り込むときはこれに合わせる。取り込んだアセットの出典とライセンスは [credits.md](credits.md) に記録する。

出典: `memo/asset.md` の案を、2026-10-11 のチャットで確定。

## ドット絵
| 項目 | 規格 |
| :--- | :--- |
| タイルの大きさ | 16 × 16 px |
| キャラクターのスプライトの大きさ | 32 × 32 px（予言者。下の「予言者のスプライト」） |
| カラーパレット | 地表のタイルは DB16（Dawnbringer 16）。キャラクターは DB16 に限らず自由な色でよい（例外。2026-10-11 に確定） |
| テクスチャのフィルタ | Nearest（ミップマップなし。`.agent/rules/godot.md`） |

## 予言者のスプライト

出典: 2026-10-11 のチャットで確定（[画面の演出](domain/ambience.md)）。大きさと色は、届いた絵に合わせて同日に 16 × 16・DB16 から変更した。

| 項目 | 規格 |
| :--- | :--- |
| ファイル形式 | PNG（RGBA 8bit、背景は透明） |
| 色 | 自由な色でよい（DB16 に限らない）。半透明やアンチエイリアス（中間色）は使わない |
| 1コマの大きさ | 32 × 32 px。余白を含めて、全コマ同じ大きさにする |
| 待機アニメーション | `game/assets/sprites/prophet_idle.png`。2〜4 コマを左から再生順に横一列につなぐ（2コマなら 64×32、4コマなら 128×32）。コマの間に隙間を入れない。コマ数は横幅 ÷ 縦の高さで決まる |
| 倒れた姿 | `game/assets/sprites/prophet_fallen.png`。32 × 32 px の1コマ |
| 足元 | 足の一番下のドットを、絵の最下段（y = 31）に置く。地表の上端に接地させる位置合わせに使う |
| 向き | 右向き |

ファイルが無い間は、コードで作る仮の絵（単色の人形）を表示する。ファイルを置いたら Godot エディタで一度開き、読み込み（`.import`）をエディタに作らせる。

## 住人の欲求の印

出典: 2026-10-14 のチャット（[カメラの視点](domain/camera-views.md)）。

| 項目 | 規格 |
| :--- | :--- |
| ファイル（欲求） | `game/assets/sprites/icon_need_hunger.png`（空腹）・`icon_need_shelter.png`（住居）・`icon_need_sanity.png`（SAN 値。今の画面で使う 3 枚）、`icon_need_social.png`（交流）・`icon_need_esteem.png`（承認）・`icon_need_actualization.png`（自己実現）・`icon_need_health.png`（体力） |
| ファイル（状態） | `icon_state_rampage.png`（狂乱）・`icon_state_catatonia.png`（自閉・絶望）・`icon_state_dead.png`（死） |
| ファイル形式 | PNG（RGBA 8bit、背景は透明。半透明やアンチエイリアスは使わない） |
| 大きさ | 12 × 12 px（2026-10-14 に 8 × 8 から変更。王冠・電球・剣の細部が残るため） |
| 色 | 自由な色でよい |

出典: 画像生成で作った 1 枚の絵（5 × 3）から 10 個を切り出し、白い背景を透明にして 12 × 12 px に縮め、縁を 2 値（透明か不透明）にそろえた。自閉・絶望の顔だけ、左右対称に手で整えた。画面で使うのは、欲求の 3 枚（空腹・住居・SAN 値）と、状態の 2 枚（狂乱・自閉・絶望）。交流・承認・自己実現・体力・死は置いてあるだけ。ファイルが無いときは、コードで作る単色の仮の絵（橙・茶・紫）を表示する。ファイルを置いたら Godot エディタで一度開き、`.import` を作る。

## 画面（`project.godot`）
| 設定 | 値 |
| :--- | :--- |
| ビューポートの幅（`display/window/size/viewport_width`） | 480 |
| ビューポートの高さ（`display/window/size/viewport_height`） | 270 |
| 拡大のモード（`display/window/stretch/mode`） | `viewport` |
| 縦横比（`display/window/stretch/aspect`） | `keep` |
| 拡大率（`display/window/stretch/scale_mode`） | `integer`（整数倍だけ） |

480×270 の画面を整数倍に拡大して表示し、ドットの幅をそろえる（ピクセルパーフェクト）。ウィンドウの大きさによっては、上下左右に黒い帯が出る。ドット絵の品質を優先し、これを受け入れる。
