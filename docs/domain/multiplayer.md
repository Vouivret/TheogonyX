## 目的

複数の神（プレイヤー）が、同じ星に神託を打ち込めるようにする。そのための最初の一歩として、神託の操作を直接実行するのをやめ、すべて「命令」として順番に積み、決まった順に実行する形にする。1 人用のままでも、同じ操作・同じシードから同じ結果になることを命令の列で確かめられる。

## 決定

2026-10-14 のチャットでの決定。

| 項目 | 決定 |
| :--- | :--- |
| 時間の進め方（多人数のとき） | 一定の速さで自動に進める。跳躍（50〜300 年の一括）は無し |
| 通信の形 | 同じ LAN の中。ホストが全員の命令を集める（今のスマホ接続の延長）。中継サーバーは作らない |
| 着手の範囲 | 指示書の Step 1（命令を待ち行列に積んでから実行する）だけ |

## ゲームのルール

用語は [用語集](glossary.md) に合わせる。

### 神託の命令

- 神託に関わる操作（夢のコマの入れ替え＝改ざん、神託を下す）は、PC の画面からもスマホからも、直接は実行しない。「命令」にして、待ち行列に積む。
- 命令は、次を持つ。
  - 種類（改ざん・神託を下す）と、その引数（改ざんなら夢のコマの番号と記号）
  - 積んだ年（今の年）
  - 順番の番号（ホストが積んだ順に 1 から振る。通し番号）
- 待ち行列の実行は、**積んだ順（順番の番号の順）**に 1 つずつ行う。
- 命令は、積んだフレームのうちに、次の 1 年の計算より前に実行する。時間が止まっているあいだも同じ（画面の反応が遅れない）。
- 実行したときに今はできない命令（夢なし・改ざん済みでの改ざん・崩壊後など）は、何も変えずに捨てる。表示は今の状態に戻す（今の[夢の改ざん](dream-tampering.md)の規則と同じ）。
- 命令の実行の結果は、今の直接の操作と同じにする。1 人用の動きは変えない。
- 待ち行列に残った命令はセーブしない（積んだフレームのうちに空になるため）。

### 同じ操作からは同じ結果

- 同じシード・同じ初期の状態・同じ命令の列（年と順番の番号と中身）からは、同じ星の状態・ドグマの一覧・年表になる。
- この性質を、命令の列を再生するテストで確かめる。

### 多人数のときの時間

- 多人数のあいだは、一定の速さで自動に進める。100 年跳躍と世界再創生の操作は出さない（決定）。
- 速さの値と、世界再創生の扱い（多人数のとき誰ができるか）は[未決](#未決)。
- 1 人用のとき、今の時間の操作（跳躍・自動進行・速さ）は変えない。

### 構想（Step 1 の範囲外）

指示書にある次の機能は、前提の仕組みができてから決める。この仕様書の受け入れ条件には入れない。

| 機能 | 前提の仕組み | 今あるか |
| :--- | :--- | :--- |
| 複数の神（Player ID）・神ごとのデッキと夢 | 神のモデル（ドグマの持ち主・夢・手札を神ごとに持つ） | 無い（神は 1 人） |
| 地域ごとの信仰シェアと神権支配 | 住人の祈り・信仰（[神託のデッキ](oracle-deck.md)の神威と同じ前提） | 無い |
| 神託の干渉（相殺・合成） | ルーンの対応表（[神託のデッキ](oracle-deck.md)）・技術と文化の値 | 無い |
| 非対称な神の権能 | 神ごとの初期デッキ・パッシブ | 無い |
| 状態のハッシュ照合（100 Tick ごと） | 住人・建物・年表・地層を含めた全状態のハッシュ | 無い |
| 複数のコンパニオンの接続 | 今は配信を同時に 2 台まで | 部分的 |

## 受け入れ条件

| ID | Given（前提） | When（操作） | Then（結果） |
| :--- | :--- | :--- | :--- |
| AC-multiplayer-001 | 夢が 木(0.5) → 雨(0.6) → 火(0.4) の星 | 「2 番目を血に入れ替える」「神託を下す」の命令を、この順に積んで実行する | 直接操作したときと同じ結果（血の禁忌などのドグマが一覧に加わり、夢が空になる。[夢の改ざん](dream-tampering.md) AC-012 と同じ） |
| AC-multiplayer-002 | 夢が改ざん前の星 | 「2 番目を血に」「2 番目を火に」の命令を、この順に同じフレームで積む | 順番の番号が小さい方（血）だけが効く。後の命令は何も変えずに捨てられる |
| AC-multiplayer-003 | 夢なしの星 | 「神託を下す」の命令を積む | 何も変わらない。ドグマは加わらず、状態は変わらない |
| AC-multiplayer-004 | 同じシード・同じ初期の星と、同じ命令の列（年・順番の番号・中身） | 2 回、列を再生して年を進める | 世界の状態・ドグマの一覧・年表が一致する |
| AC-multiplayer-005 | 命令を積んで、同じフレームのうちに実行した星 | 保存して読み込む | 待ち行列は空で、ドグマの一覧と夢の状態は保存前と同じ |
