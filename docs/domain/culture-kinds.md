## 目的

人の営みを、現実の文化の分類に沿った種類で満たす。家の形・言葉・文字・治め方・道具・衣服・料理・神話が、気候・手に入る材料・技術・信仰から決まり、地域ごとに違う文化が育ち、混ざり、分かれていく。種類の名前は、地表の絵・住人の暮らし・年表・予言者の語りに現れる。

## ゲームのルール

用語は [用語集](glossary.md) に合わせる。[自然の種類](natural-kinds.md)と同じ形で書く: 現実の分類から取った最初の案を表にし、種類の表はデータ定義に置いて、後からいくらでも足せるようにする。絵を描くのは大分けだけ、細分けは名前とデータだけ（2026-10-14 に決定した自然の種類の方針に合わせる）。

### 共通の方針（案）
- 文化の種類は、**地域ごと**に持つ（地域の文化）。住人は、住む地域の文化で暮らす。
- 文化は、気候・植生・手に入る材料・技術・信仰から、現実の決まりで決まり、隣の地域と混ざり、離れると分かれる。
- 決め方・混ざり方・分かれ方は、シードを指定した乱数を使う決定的な計算にする。

### 生まれ方と変わり方（2026-10-15 に決定）
- **言葉は、行き来が少ないと分かれる**: 始まりの狩猟採集の群れごとに言葉を持つ（[人の数](population.md)）。行き来の少ない集団どうしは、時間とともに言葉がずれ、ずれが決まった量を越えると新しい言葉になる（系統樹ができる）。行き来が多いと、ずれは戻る（単語の貸し借り）。現実の言語年代学の目安は、1,000 年で基本の単語の約 2 割が入れ替わる。言葉は人のまとまりの文化の軸（[人の数](population.md)）で持ち、[国と集落](polity.md)の独立の「言葉のずれ」に使う。
- **建築・衣服・料理は、環境と発明から決まり、そこに伝播が重なる**: 植生・土・鉱物・気候と、知っている発明（[発明の木](invention-tree.md)）から形が決まる（森なら木の家、乾いた土地なら日干し煉瓦、寒い所では毛皮）。隣との行き来で、飾りや好みが伝わる。[服装と流行](fashion.md)の「実用がメイン、流行は見た目」と同じ考え方。
- **文化の値（`CultureVector`）は、文化の要素の集まりから求める値にする**: 発明の木と同じく、地域が知っている文化の要素（文字・法・暦・祭りの形など）の集まりを持ち、`CultureVector` はそこから求める。建物が建つ閾値・建物の絵のプロンプトは、それを使い続けられる。
- **名前は、言葉ごとの音で作る**: 言葉ごとに、音の組み合わせ（音節のパーツ）を乱数で（シードを指定した乱数）決め、その言葉の人・集落・国の名前をそこから作る。言葉が分かれると、音も少しずつずれる。名前を見れば、どの文化の人かが分かる。宗派の名前は AI が作る（[宗教](religion.md)）。

### 言葉の速さ・行き来・名前・家の絵（2026-10-16 に決定）
- **言葉は、行き来が無いとおよそ 1,500 年で分かれる**: ずれは、1,000 年で基本の単語の 2 割が入れ替わる速さで溜まる。行き来がほとんど無ければ、およそ 1,500 年（仮）で別の言葉になる（ラテン語からフランス語・スペイン語などへ）。行き来が多いほど、ずれは戻る。およそ 1 万年の歴史で、系統樹が数段になる。
- **行き来の量は、移住・交易・同じ国・巡礼を足す**: 地域の組ごとに、その年の移住の人数（[人の数](population.md)）・道の網の交易の量（[運送と物流](logistics.md)）・同じ国か（[国と集落](polity.md)）・巡礼の人数（[聖地](holy-site.md)）を重みづけて足す。ほかの仕組みがすでに出す量を使う。治められると、治める側の言葉の単語を借りる（ノルマン人に治められた英語が、フランス語を借りたように）。文化の要素の伝わり方も、同じ行き来の量を使う。
- **名前は、すべての言葉で音を作る**: 今の 36 通りのパーツ（`ui.csv` の `NAME_*`）はやめ、すべての言葉の音節のパーツを、シードを指定した乱数で作る。
- **家の絵は、様式の絵をすべて作り直す**: 建物の絵は、建築の様式 × 時代の名札（[発明の木](invention-tree.md)）で選ぶ。今の技術の値で変わる 3 種類の家の絵はやめる。技術の値（`TechVector`）は、発明から求める値になる。
- **名前の音は、カタカナで書ける音で作る**（2026-10-16 に決定）: 音節は「子音 ＋ 母音」と「ン」「ッ」「ー」だけで作る。言葉ごとに、使う子音・母音、音節の数、よく使う語尾を乱数で選び、響きを変える（ハワイ語は子音が少なく、母音で終わる音節ばかり、のような違い）。日本語はカタカナ、英語はローマ字にそのまま変えられるので、どちらでも響きが崩れない。
- **名前を切り替える時期**（2026-10-16 に決定）: 段 3a（人のまとまりと、群れごとの言葉ができる段。[ロードマップ](../roadmap.md)）で切り替え、`ui.csv` から `NAME_*` を外す。セーブの版を上げるので、古いセーブは読めなくてよい（ロードマップの決定どおり）。
- **絵を作り直す時期**（2026-10-16 に決定）: 1b で、星の地図の集落を 1 つの記号（人口で 1 マス → 3 × 3 → 5 × 5 と広がる。[国と集落](polity.md)の「縮尺」）で描き、今の 3 種類の家の絵は星の地図ではやめる（段 3 から、詳細の視点の街並みで家の絵を使う。2026-10-17 に決め直した）。様式 × 時代の絵は、文化の種類を入れる段 8 で作る。それまでは、様式の無い集落の記号だけ。
- **絵の数**（2026-10-16 に決定）: 建築の様式の大分け（下の表の数）× 時代の名札の大きな 4 つ（原始・古代・中世・近代）。細分けは、色の差し替えと飾りで出す（[服装と流行](fashion.md)と同じやり方）。

### 言葉の系統（細分けは名前だけ）
地域ごとに言葉を持つ。はじめは近い地域どうしで同じ言葉を話し、交わりが少ないまま年月がたつと、方言 → 別の言葉へ分かれる。言葉が違う地域の記録は、読み違えやすい（構想「歴史の誤訳と聖書」）。住人の名前の響きも、言葉で変わる。

- 現実の語族を、名前の響きの型として使う（言葉そのものは作らない）。

| 響きの型（現実の語族から） | 名前の響きの例（案） |
| :--- | :--- |
| 印欧の型 | 子音のつながり、-os・-us・-a の終わり |
| シナ・チベットの型 | 短い音節の組み合わせ、声調を思わせる繰り返し |
| アフロ・アジアの型 | 子音の骨組み（k-t-b など）、-at・-un の終わり |
| オーストロネシアの型 | 母音が多く、繰り返しの多い音（-a・-i の終わり） |
| ウラル・アルタイの型 | 母音の調和、-an・-ur の終わり |
| ニジェール・コンゴの型 | 前に付く音（ba-・ki-）、母音の終わり |
| アメリカ大陸の諸語の型 | 長い合わせ言葉、-tl・-co の終わり |
| 孤立した言葉 | どれにも似ない響き（山や島に残る） |

- 分かれ方: 隣と交わる量（移住・巡礼・交易）が少ないほど、早く分かれる。分かれた言葉は、元の言葉の「子」として覚える（言葉の系図）。

### 文字（大分けは絵あり）
文字は、記録の必要（学問・宗教・交易）が高まった地域で生まれ、伝わり、変わる。年表の書き方・聖典・発掘での読み違えに効く。

| 段階 | 例 | 起こり方（案） |
| :--- | :--- | :--- |
| 文字の前 | 結び縄・刻み目・絵 | はじめから |
| 絵文字 | 物の形の絵 | 祠・交易のある地域 |
| 表語文字 | 楔形文字・神聖文字・漢字のような字 | 学問・宗教の中心 |
| 音節文字 | 音の区切りを表す字 | 表語文字から崩れて |
| 字母（アルファベット） | 1 つの音に 1 つの字 | 交易の多い地域で、他所の字を借りて |
| 失われた文字 | 読めなくなった古い字 | 文字を使う人が絶えたとき。発掘されても読めない |

### 統治の形（大分けは絵あり）
地域で「誰が決めるか」の形。人の数・食べ物の余り・信仰・争いで移り変わる。抜けていた「統治・指導者」と、構想「階級と貴族」の土台。2026-10-15 に、統治の枠組みを「国」として地域・集落と分けて持つ案を受け取った（[国と集落](polity.md)）。この表を国の統治の形に使うかは、そちらの未決。

| 形 | なりやすい条件（案） | 決める人 |
| :--- | :--- | :--- |
| 群れ | 人が少ない・食べ物の余りが無い | 皆で話し合う |
| 部族 | 人が増える・家族のつながり | 長老 |
| 首長制 | 食べ物の余り・争い | 首長 |
| 王政 | 大きな人口・城・軍 | 王（世襲） |
| 神権政治 | 信仰の強い地域・宗派の中心 | 宗派の長・神官 |
| 都市国家 | 交易の多い沿岸・平野 | 有力な家々の会議 |
| 共和制 | 学問・交易が育った地域 | 選ばれた人々 |
| 帝国 | 戦で多くの地域を従えた | 皇帝 |
| 無政府・崩壊 | 飢饉・疫病・狂乱 | 誰もいない |

### 未決だったことの決め方（2026-10-17 に AI の推奨で決め、人間が一覧で確認した）
