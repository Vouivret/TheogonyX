# 仕様書: 画面の演出（昼夜の環境光と予言者）

- テスト仕様書: [docs/test/ambience.md](../test/ambience.md)
- 関連ADR: なし
- 通信: なし
- 画面デザイン: なし。アセットと画面の規格は [docs/art-guide.md](../art-guide.md)
- 出典: 2026-10-11 のチャットでの確定仕様（ロードマップ M1「2D ライティングとドット絵の予言者」）

## 目的

単純なアニメーションと環境光で、星を「生きたアクアリウム」として眺められるようにする。世界の状態（カオス度・崩壊）が、画面の色と予言者の姿にも表れるようにする。

## ゲームのルール

用語は [用語集](glossary.md) に合わせる。ここでの演出は見た目だけで、シミュレーションの結果には影響しない。

### 昼夜の環境光

- 地表と予言者の画面全体に、環境光の色をかける（Godot の `CanvasModulate`）。HUD にはかけない。
- 昼夜の周期は、ゲーム内の年とは関係なく、実際の時間で 12 秒である。100年跳躍や自動進行の速さに影響されない。
- 周期の中に、次の4つの色を 3 秒おきに置き、隣どうしの色を経過時間に比例して補間する（線形補間）。朝の後は青空に戻る。

  | 経過時間（周期の中） | 色 |
  | :--- | :--- |
  | 0 秒 | 青空 |
  | 3 秒 | 夕焼け |
  | 6 秒 | 夜 |
  | 9 秒 | 朝 |
  | 12 秒（= 次の周期の 0 秒） | 青空 |

- 色の値は、ゲームデータ定義（`game/data/rules.json` の `ambience`）に置く。DB16 を元にする。

### カオス度による色の変化

- 上で求めた昼夜の色を、カオス度 ÷ 100 の割合で、紫赤の色へ補間する。
  - カオス度 0 なら昼夜の色のまま、50 なら昼夜の色と紫赤の中間、100 なら紫赤そのものになる。
- 紫赤の色の値は `rules.json` の `ambience` に置く。

### 崩壊したとき

- 星が崩壊したら、昼夜の周期を止め、環境光を赤黒の色に固定する。カオス度による変化もかけない。
- 予言者を、倒れた姿に変える（待機アニメーションは止まる）。
- 赤黒の色の値は `rules.json` の `ambience` に置く。

### リセットしたとき

- 予言者を立った姿に戻し、待機アニメーションを再開する。
- 昼夜の周期は最初からやり直さず、止まったところから続ける。崩壊していなかったときは、そのまま続く。

### 予言者

- 地表の上に1体、固定の位置に立たせる。
  - 左右: 地表の左から 8 列目（1 列目から数える）を左端にする。絵の幅が 32 px なので、8〜9 列目にまたがる。
  - 上下: 地表の一番上の行のタイルの、すぐ上に立たせる（足元が地表の上端に接する）。
- 待機アニメーション（呼吸・瞬き）を、1 コマ 0.5 秒でループさせる。コマ数は、絵の横幅から決める（横幅 ÷ 1 コマの幅）。
- 列の位置と 1 コマの秒数は、`rules.json` の `prophet` に置く。
- 絵の形式は [art-guide.md](../art-guide.md) の「予言者のスプライト」に従う。絵が届くまでは、コードで作る仮の絵を使う。

## 受け入れ条件

色は `#RRGGBB`、または各成分を 0〜255 で書く（例: (232.5, 190, 149.5)）。昼夜の色は、青空 `#FFFFFF`、夕焼け `#D27D2C`、夜 `#30346D`、朝 `#DEEED6`、紫赤 `#D04648`、赤黒 `#442434` で計算した。

| ID | Given（前提） | When（操作） | Then（結果） |
| :--- | :--- | :--- | :--- |
| AC-ambience-001 | カオス度 0、崩壊していない | 周期の 0 秒の環境光を求める | 青空 `#FFFFFF` |
| AC-ambience-002 | カオス度 0、崩壊していない | 周期の 3 秒の環境光を求める | 夕焼け `#D27D2C` |
| AC-ambience-003 | カオス度 0、崩壊していない | 周期の 1.5 秒の環境光を求める | 青空と夕焼けの中間 (232.5, 190, 149.5) |
| AC-ambience-004 | カオス度 0、崩壊していない | 周期の 10.5 秒の環境光を求める | 朝と青空の中間 (238.5, 246.5, 234.5) |
| AC-ambience-005 | カオス度 0、崩壊していない | 経過時間 15 秒の環境光を求める | 夕焼け `#D27D2C`（12 秒で周期が戻る） |
| AC-ambience-006 | カオス度 50、崩壊していない | 周期の 6 秒の環境光を求める | 夜と紫赤の中間 (128, 61, 90.5) |
| AC-ambience-007 | カオス度 100、崩壊していない | 周期の 0 秒の環境光を求める | 紫赤 `#D04648` |
| AC-ambience-008 | カオス度 40、崩壊している | 周期の 3 秒の環境光を求める | 赤黒 `#442434` |
| AC-ambience-009 | メインシーンを実行した | 画面を見る | 地表の左から 8 列目の上に予言者が立ち、0.5 秒ごとにコマが変わる。環境光が 12 秒で青空 → 夕焼け → 夜 → 朝 → 青空と変わる。HUD の色は変わらない |
| AC-ambience-010 | 星が崩壊した | 画面を見る | 環境光が赤黒で止まり、予言者が倒れた姿になる |
| AC-ambience-011 | 星が崩壊している | リセットする | 予言者が立った姿に戻り、昼夜の周期が止まったところから続く |

## 対象外

- 焚き火の明かり（`PointLight2D`）と夜空の星: ロードマップ M1 にあるが、今回の確定仕様に入っていない。
- 予言者が歩く・複数いる: M3（大量 NPC）で扱う。
