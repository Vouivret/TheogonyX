## 目的

神託を、数値の操作ではなく「抽象概念を世界に落とし、人間の環境・技術・SAN 値に応じて解釈され、ときに暴走するもの」にする。何を神託にするか（[神託のデッキ](oracle-deck.md)の概念ルーン）に加えて、どう届けるか（伝達メディア）をプレイヤーが選べるようにし、世界の反応と二次誤解の幅を広げる。

## ゲームのルール

用語は [用語集](glossary.md) に合わせる。

- 神託は「概念ルーンの組み合わせ」×「伝達メディアの選択」で決まる（指示書より）。
- メディアによって、影響の範囲とリスク・リターンが変わる。
- 間接操作の理念（アクアリウム）: プレイヤーは住人のステータスや建物の数値を直接変えられない。神託は「一滴のインク」で、5 大欲求・環境・AI の思考を通って、思いもよらない形に現実へ変換される。この理念は今の仕様（神は住人を直接変えない）と同じで、すべてのメディアで守る。
- 今ある神託（夢の改ざんして神託を下す）は、メディア「夢託」の最初の形である。他のメディアは構想で、必要な仕組みができてから作る。

| :--- | :--- | :--- | :--- | :--- |
| 夢託（Dream） | SAN 値が低い、または自己実現（Level 5）の欲求が高い住人 | カオス度は上がりにくい。対象が「異端の教祖」になり、秘密集会を開くリスク | 異端の教祖・人が唱えるドグマ | 予言者の夢を改ざんして神託を下す形だけ |
| 顕現（Manifestation） | その地域全体（空・天候） | 信仰が一気に爆発するが、世界全体のカオス度と住人の SAN 値の減少が大きく悪化する | 地域への介入・天候の表現 | 無い |
| 刻印（Inscription） | 地下の地層の石碑・遺物 | すぐには働かず、数百年後に後世の人間や地底人が発掘したときに、二次誤解として定着する | 発掘と二次誤解（[地層](strata.md)） | 無い |
| 憑依・聖なる予言者（Prophetic Vessel） | 住人 1 人を「神の器」にする | 対象の頭上に光のアイコンが付き、周りの住人を集めて演説する。高い地位の住人なら神託がすぐ実行される。SAN 値 0 の貧しい住人は、狂人として投獄・追放されるが、死後に殉教者として聖人化され、数世代後にカルトの開祖になる | 地位・指導者・投獄・殉教の仕組み | 無い |
| 異変・前兆（Omens） | 地図の 1 マス（32 px）に、物理的な異常を置く（川が血の色に染まる、麦畑にミステリーサークル、空の割れ目など） | 技術の高い地域は自然現象・鉱物反応として採掘・研究施設を建てる。文化の高い地域は神の怒りとして、囲いを立てて聖地にする | 地域の技術・文化の値（[創発的な発展](emergent-progression.md)）と、解釈の分岐 | 無い |
| 天降る遺物（Fallen Artifact） | 概念を込めた物体（32 px のアセット）を特定のマスに落とす | 住人が拾って工房・神殿に運ぶ。2 つの地域の境界に落ちると奪い合いの戦争の引き金になる。解読すると新しい概念ルーンが開き、住人が異人種に変異し始める | 運搬タスク・[戦争](warfare.md)・遺物の研究・異人種 | 無い |
| ミーム感染・流行歌（Viral Song） | 1 人の住人から、会話（交流の欲求）と物資・鉄道を通って 16 地域へ広がる | 遠くの地域へも広がる。聴いた住人が集団でトランス状態になり、理由も分からず同じ奇妙な建築物（巨大な塔など）を建て始める | 住人どうしの感染・交通網・建築の乗っ取り | 無い |
| 聖典の筆写・誤植（Sacred Manuscripts） | 工房・図書館に 1 冊の書物を生む。人が書き写して広める | 別の地域へ書き写されるたびに、乱数で誤字・脱字（二次誤解）が必ず起きる。例: 原本「隣国と平和を保て」→ 3 回書き写すと「隣国を平らげよ」 | 書物・複製・工房と図書館・テキストの変質 | 無い |

### 選び方と結果（選択 × 条件による結果）

2026-10-14 のチャットでの提案「ア案」を、仕様の方針として書く（人間が決め直す）。

- 伝達メディアは、プレイヤーが**選ぶ**。毎回の作業になりすぎないための手数の減らし方は[未決](#未決)。
- 選んだメディアと、届け先の地域の条件（インフラ・SAN 値・文化・技術・種族・建物）をコアが判定し、結果を決める。選んだものがそのまま効くとは限らない。
- 結果は、次の 4 つのどれかに、シード付きの乱数で決定的に分かれる（同じシード・同じ条件からは、同じ結果になる）。

  | 結果 | 意味 |
  | :--- | :--- |
  | 大成功 | 条件が揃い、神託が意図どおりに広がる |
  | 暴走 | 条件が歪み、広がり方や中身が思わぬ形になる（二次誤解） |
  | 異端化 | 受け手が神託を自分の教義に変える（異端の教祖・カルト） |
  | 失敗 | 届かずに消える（空振り） |

- 条件の例（指示書の例。値と判定の式は未決）:

  | 選んだメディア | 条件を満たさない | 条件を満たす |
  | :--- | :--- | :--- |
  | 流行歌 | 線路も道路も無い孤立した地域では、隣に広がらず、その地域だけで消える（空振り） | 線路が通っていれば、16 地域へ一気に広がり、文明を一変させる |
  | 憑依 | 全員の SAN 値が低く狂乱寸前なら、狂人として処刑され、効果がすぐ終わる | SAN 値と文化の高い住人がいれば、崇高な聖者として神託を広める |

- 「選べるが世界に振り回される」ので、プレイヤーは世界（16 地域のインフラ・SAN 値）を観察してから、どこにどう届けるかを選ぶ。実験を狙いつつ、結果は人間に任せる体験にする（アクアリウムの理念）。
- 概念ルーンと伝達メディアは、**別々に選ぶ**（2026-10-14 に決定）。手札から「何を」（ルーン）を選び、「どう届けるか」（メディア）は別に選ぶ。メディアはデッキのカードにしない。選べるメディアは、必要な仕組みができたものから増える。[神託のデッキ](oracle-deck.md)の仕様は変えない。

### 決定性

- 解釈の分岐・感染・筆写の誤り・変異は、シード付きの乱数と、データ定義の表で決まる（同じシード・同じ操作からは、同じ結果になる）。
- 文を見せる部分（演説・聖典の文面・流行歌の歌詞など）の AI による表現は、[AI による表現](ai-presentation.md)の方針どおり、ゲームの計算に影響しない。
