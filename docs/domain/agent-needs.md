## 目的

人が自分の欲求に従って暮らし、満たされれば崇められたい・真理を知りたいと上を目指し、飢えや災害では生き延びることだけに走る様子を見せる。神（プレイヤー）のドグマが人の体と心を変え、そこから予想できないドラマ（狂乱・絶望・異端の教祖）が生まれるようにする。

## ゲームのルール

用語は [用語集](glossary.md) に合わせる。この節の多くは指示書の内容を写したもの。M5 で最初に作るものは、下の「M5 で作る最初の範囲と値」で決め、食い違うところ（睡眠の欲求・1 日ごとのタスクなど）はそちらを優先する。

### 決定性の境界
- 欲求・健康・タスクの選択・精神崩壊・変異は、すべてコアがシードを指定した乱数（`System.Random`）で決める。同じシード・同じ入力からは同じ結果になる。
- 人の ID は通し番号で振る（`Guid.NewGuid()` は実行ごとに変わり、決定性が壊れる）。座標はコアで定義した型を使い、Godot の型（`Vector2` など）を使わない。
- AI（LLM・画像生成）は、コアが決めた結果を語る・描くだけにする（[AI による表現](ai-presentation.md)と同じ）。
- 同じシードで、欲求のたまり方・精神崩壊が起きる時・選ぶタスクが毎回同じになることを、自動テストで保証する。

### 欲求の 5 段階
- 人は 6 つの欲求を持つ。値は 0.0（満たされている）〜 1.0（切実）で、時間とともに増え、行動で減る。

  | 段階 | 欲求 | 満たす行動の例 |
  | :--- | :--- | :--- |
  | L1 生理的欲求 | 空腹（`NeedHunger`）・睡眠（`NeedSleep`） | 食事、眠る、体温を保つ（焚き火・水） |
  | L2 安全の欲求 | 住居（`NeedShelter`） | 屋根のある家、災害・野獣から逃げる、医療 |
  | L3 社会的欲求 | 交流（`NeedSocial`） | 仲間との会話、集会・祭り、つがい |
  | L4 承認・尊厳 | 承認（`NeedEsteem`） | 暗黒議会の議員になる、装飾品・立派な家、地位 |
  | L5 自己実現 | 自己実現（`NeedActualization`） | 新しいドグマを唱える、独自の巨大建築・碑文、芸術・極秘研究、異教の儀式 |

- 下の段階の欲求が満たされていないと、上の段階の欲求からはタスクを選ばない（L1・L2 が閾値より下のときだけ、L3〜L5 を評価する）。
  - 平常時: 腹が満ち、家がある → 崇められたい（L4）→ 真理を知りたい（L5）→ 勝手に新しいドグマを唱え始める。
  - 飢え・災害のとき: L3〜L5 をすべて止め、食料の奪い合いと避難（L1・L2）だけをする。

### タスクの選び方
- 人は、次の順にタスクを選ぶ。
  1. 精神崩壊中なら、崩壊の行動（狂乱 → まわりを壊す、自閉・絶望 → 何もしない）。
  2. 下の段階から順に、閾値を越えた欲求のタスク（空腹 → 食料を探す、睡眠 → 眠る、住居 → 家を建てる）。
  3. L1・L2 が満たされていれば、交流 → 広場に集まる、承認 → 装飾品を作る、自己実現 → 新しいドグマを唱える。
  4. どれでもなければ、何もしない（`Idle`）。

**家（2026-10-13 に決定）**
- その年に「屋根を探す」を選んだ住人が 1 人以上いる地域に、家を 1 軒建てる。地域の番号の順に処理し、1 つの地域で 1 年に 1 軒まで。
- 建てる枠は、工房・祠と同じ選び方（2 × 2 マスがすべて草地の空き枠から、廃墟のある枠を先に、乱数で選ぶ）。寿命（200〜400 年）も同じ。乱数は住人の計算の乱数（シード・年・地域）を使う。空き枠が無ければ建たない。
- 家の種類は、建った年の地域の技術の段階（越えた閾値の数）で決め、建った後は変えない。段階 0 はわらぶき小屋（`HouseHut`）、1〜2 は木組みの家（`HouseTimber`）、3〜4 はれんがの家（`HouseBrick`）。
- 建った家は、次の年の住居と住人の上限から数える。
- 家は工房・祠と同じく、寿命で廃墟になり、150 年で地下に沈み、世界再創生でも地下に沈み、狂乱で壊される（[地層](strata.md)）。文明の計算で建て直す数（技術・文化の段階）には、家を数えない。
- 画面: 家の種類ごとの絵で描く。廃墟の上に建て増しした家は、種類にかかわらず石の土台の上の家（2 階建て、32 × 48 px）で描く。
- 選んだタスクの目的のマス（食料・祭壇・広場など）へ移動する。

### 肉体の健康
- 体力（`Health`、0〜100）は、空腹・極寒・負傷・老衰で減る。0 になると死に、そのマスに墓（死体）を置く。
- 状態異常:
  - 負傷: 移動が遅くなる。手当て（医療）をしないと感染症になる。
  - 疾患・聖病: 自然に起きる病気のほか、ドグマ（赤き雨など）で体がヒレ・エラに変わっていく（海底人への変異の途中）。体力が減る代わりに、変異が進む。
  - 老衰: 年を取るにつれて、体力の上限が下がる。

### 精神の健康（SAN 値）
- SAN 値（`Sanity`、0〜100）は、仲間の死・恐怖のドグマ・カオス度の上昇で減る。
- SAN 値が 0 になると、シードを指定した乱数で次のどれかの精神崩壊になる。
  - 狂乱（`Rampage`）: まわりの建物・人を壊す（カオス度は上げない）。
  - 自閉・絶望（`Catatonia`）: 食事を拒み、神への呪いの言葉をつぶやき続ける。
  - 異端の教祖（`CultLeader`）: 自分で作ったドグマをまわりに感染させ、カルトを作る。

### つがいと世代交代
- 人は、繁殖の欲求（`NeedLibido`）と愛着の欲求（`NeedAffection`）を持つ（0.0〜1.0）。L1・L2 の欲求が満たされているとき、時間とともに増える。
- 求愛・つがい・子供をもうけることができるのは、大人の年齢以上の人だけとする（2026-10-13 に決定。年齢は 16 歳）。
- 流れ（どれもコアがシードを指定した乱数で決める）:
  1. 求愛: 欲求が高まると、近くでいちばん好感度の高い相手のところへ行き、求愛する。
  2. つがい: 双方が同意すると、パートナーになり、同じ家（住居）に住む。
  3. 世代交代: つがいから、一定の確率で子供が生まれる。親の性質（ドグマへのなじみやすさ・種族の変異）が子供に引き継がれる。
- 人どうしの関係: 独身・交際中・夫婦・敵。好感度は −1.0〜1.0。
- 恋愛のもつれ: 求愛を断られる・パートナーを奪われる・好感度が急に下がると、SAN 値が大きく減る。SAN 値が 0 になったときの精神崩壊に、恋がもとの形（心中、恋敵やパートナーへの襲撃）が加わる。
- ドグマとの関わり（指示書の例）:
  - 「快楽・愛の崇拝」: 繁殖の欲求が減りにくくなり、街じゅうが愛を語らう楽園になる。人口が増えすぎて食料が足りなくなる。
  - 「禁欲・純潔」: 欲求を抑えられた人の SAN 値が少しずつ減り続け、裏で秘密のクラブができるか、人口が減って文明が衰える。
- 異なる種族の間の子供: 陸の人と海底人の子供は、両方の環境に適応した半魚人になる。陸でも海でも暮らせるが、どちらの種族からも異端として扱われる。
- 画面では、愛の営みを象徴的な表現（同じ家に入る、ハートのアイコンなど）にとどめる（2026-10-13 に決定）。

### 名前と称号
- 人は、生まれたときに名前を持つ。名前は「名（First Name）・家名（Lineage）の 称号（Epithet）」の 3 つの部分でできている。
  - 例: 「アルトリウス・イリアス の 柱を築く者」、「ギル・ルルイエ の 深海の狂信者」（海底人）
- 名と家名は、種族と地域の文化の値に応じて、音のパーツ（接頭辞 ＋ 接尾辞）を組み合わせて作る。組み合わせはコアがシードから決める。
  - 陸の人（古典神話・英雄伝風）: 接頭辞 アルト-・ヴァル-・イリオ-・エル-・セレ-・オル-、接尾辞 -トリウス・-ウス・-フィア・-ギス・-ミオン・-ア
  - 海底人・深海の種族（異形の神話・深海風）: 接頭辞 ギル-・ダゴ-・ルル-・ゾス-・クル-・ヴォル-、接尾辞 -イエ・-アシュ・-トル・-グア・-イン
- 名前を作る乱数は、シミュレーションの乱数と分ける案にする（2026-10-13）。「シード × 人の通し番号」から作る別の乱数（群衆の `CrowdHash` と同じ考え方）にすれば、名前を足しても、戦争や建物などほかの結果は変わらない。
- 子供は、親の家名を引き継ぐ（どちらの親かは、名前の乱数で選ぶ。2026-10-13 に決定）。
- 称号は、行いで得る（指示書の例）。

  | きっかけ | 称号の例 |
  | :--- | :--- |
  | 建物をいくつも建てた | 街を包む者 |
  | 精神崩壊（狂乱など）を起こした | 血を恐れぬ者 |
  | 強いドグマを信じている | 赤き雨の証人 |
  | 戦争で敵の地域を壊した・占領した | 廃墟の征服者 |
  | 老衰 | （指示書に例が無い） |

- 人が死ぬと、名前と称号を歴史の記録（`HistoryLog`）に残す。地下の地層にも残し、発掘したときに読めるようにする（[地層](strata.md)の未決）。
- 名前と称号は表現で、ゲームの計算には関わらない。

### 人のまとまりとのつなぎ方（2026-10-16 に決定。人のまとまりを入れる段 3a から）
今の住人の決まり（一人ずつ食料と森を使う・自分で家を建てる・家 × 4 の上限）は、住人が数十人の今の星のもの。人のまとまり（[人の数](population.md)）と市場（[経済の進化](economy.md)）ができたら、次のように読み替える。
- **欲求は、属するまとまりの暮らしの段に従う**: 住人の空腹・住居・交流・承認・自己実現は、属するまとまりがその年に暮らしの段をどこまで買えたかを土台にし、住人ごとの気質と乱数で少しずれる。住人が一人で食料や森を使う計算はやめる。貴族の家（[貴族と家](nobility.md)）と名のある商人は、自分の富で買う。
- **家は、詳細の視点の絵だけ**: 住人が家を建てる計算（家 × 4 の上限・屋根を探す）はやめる。住人は集落に住み、詳細の視点では集落の中の家の絵として描く（[カメラの視点](camera-views.md)）。住人の数は、人口の対数と物語の役で決まる（[人の数](population.md)。2026-10-15 に決定済み）。称号「街を包む者」は、集落を興した人などに読み替える。
- **死は、まとまりと同じ原因を一人ずつ乱数で**: 老衰（今のまま）に加え、飢え・疫病・寒さ・戦（兵なら）で、その年のまとまりの死ぬ割合を、一人ずつシードを指定した乱数で当てる（[疫病](plague.md)・[エネルギー](energy.md)・[地域間の戦争](warfare.md)）。精神崩壊・暗殺など、住人だけの死に方も残る。死んだら、まとまりから 1 人引く（決定済み）。
- **つがいは、住人どうしか、まとまりから起こす**: 同じ地域に合う住人がいればその人と、いなければまとまりから相手を 1 人起こす（[予言者の暮らし](prophet-life.md)のつがいと同じ形）。貴族の家の人は、婚姻の仕組み（政略結婚。[貴族と家](nobility.md)）で相手を選ぶ。子は、親のまとまりに属する。

### M5 で作る最初の範囲と値（2026-10-13 に決定）
指示書の内容は大きいので、M5 では「人が欲求で暮らし、飢えや恐怖で崩れ、死ぬ」までを最初に作る。値は仮の値で、`rules.json` の `needs` に置き、画面で見て調整する。

- **作らないもの（後に回す）**: つがいと世代交代（構想「世代交代と教義の変質」。最初の範囲は下の「つがいと子供の最初の範囲」で作った）、異端の教祖と人が唱えるドグマ（コアループが変わる。同じ構想と暗黒議会と一緒に決める）、変異と半魚人（構想「異人種と海中都市」）、負傷・感染症・疾患（医療と野獣・災害が無い）、歴史の記録（`HistoryLog`。構想「歴史の鑑賞」と一緒に作る）、名前の文化の値による違い。

**住人（群衆とは別の少数の人）**
- 欲求と健康を持つのは、群衆（10,000 人の点）ではなく、別に足す少数の「住人」とする。群衆は今どおり見た目だけで、GPU 版と CPU 版の突き合わせは変えない。
- 住人はコアが持ち、地域（4 × 4 の 16 地域）に属する。ID は通し番号（建物と同じく、セーブに次の番号を残す）。
- 住人の上限は地域ごとに「2 ＋ 建っている家の数 × 4」（2026-10-13 に、建物の数から家の数に変えた）。子供は、地域の人数が上限より少ないときだけ生まれる。
- 地域の正常な大人（16 歳以上で、精神崩壊していない住人）が 2 人より少なければ、その年に 1 人がよそから移り住む（20 歳、親は無し）。上限は見ない（2026-10-13 に、上限まで移り住む規則から変えた。人口は子供で増やす）。
- 移り住んだ住人の交流・承認・自己実現の欲求は 0.0（満たされている）から始まる（2026-10-13 に決定）。体力・SAN 値は 100。
- 住人は 1 年ごとの計算の中では位置を持たない（地域だけ）。画面では、地域の中で、選んだタスクの建物へ歩く・眠る などの 1 日の暮らしを繰り返して見せる。この歩き方は描画だけで、結果に影響しない（移動の方式は描画の側で決める。ポテンシャルフィールドは使わない）。
- 夜は、自分の地域の建物のそばで眠る。地域に建物が無ければ、その場で横になる。地域の外には出ない（2026-10-13 に決定。焚き火は予言者のそばに 1 つだけなので）。
- 世界再創生では、住人と墓をすべて消す（住人 0 人に戻す）。次の住人の ID は続きから振る（建物と同じ。2026-10-13 に決定）。

**つがいと子供の最初の範囲（2026-10-13 に決定）**
- 作るのは、つがい・子供・家名の引き継ぎだけ。繁殖・愛着の欲求、好感度、求愛・恋愛のもつれ、信心の引き継ぎ、種族をまたぐ子供は後に回す（下の「つがいと世代交代の決定（作るのは後）」）。
- つがい: 毎年、地域ごとに、独身で正常な 16 歳以上の住人を ID の小さい順に並べ、2 人ずつ組む。住人は性別を持たない。つがいは死ぬまで続き、精神崩壊しても続く。
- パートナーが死ぬと、残った住人は独身に戻る。その年のうちは組まず、次の年から組める。SAN 値は、ほかの住人の死と同じく 10 減るだけ。
- 子供: 地域ごとに、つがいを ID の小さい順に見て、2 人とも正常で 45 歳以下で、地域の人数が上限（その年の初めの家の数で数える）より少なければ、地域の乱数で確率 0.2 で子供が 1 人生まれる。1 人生まれるごとに人数を数え直す。その年に組んだつがいからは、次の年から生まれる。
- 生まれた子供は 0 歳で、その地域に属する。欲求は 0.0、体力・SAN 値は 100。名は新しく作り、家名は名前の乱数（シード × 子供の ID）でどちらかの親のものを選ぶ。
- 子供（16 歳未満）の欲求・体力・SAN 値・精神崩壊・死・称号は大人と同じ。タスクは「何もしない」で、家を建てず、欲求もタスクで減らない。つがいにならない。
- 画面: 子供は人の絵を 0.7 倍で描く。つがいは夜、同じ建物のそば（建物が無ければ ID の小さいほうの寝る点）に左右に並んで寝る。クリックで出る欄にパートナーの名前（独りなら「独り身」）を出す。
- 記録（ログ）: 子供が生まれたときとつがいになったときに出す。

**時間の細かさ**
- 住人の計算も、今の 1 年ごとの計算（Tick）の中で行う。1 年より細かい Tick は作らない。このゲームは数百年を跳ぶので、1 日単位で計算すると、跳躍が重くなるうえ、画面で 1 日を見分けられない。
- タスクは「その年に主にしたこと」とする。指示書の `EvaluateDailyTask` は、1 年ごとの `EvaluateYearlyTask` に読み替える。
- 睡眠の欲求（`NeedSleep`）は 1 年の単位では意味を持たないので、コアでは持たない。眠る様子は描画の 1 日の暮らしで見せる。

**欲求の動き方（1 年ごと）**
- 空腹（L1）: その年の食料で決める。森林量と水資源のどちらかが予言者の依頼（飢饉・渇き）と同じ閾値（30）以下なら飢饉の年とし、空腹を 0.9 にする。そうでなければ 0.1 にする。自閉・絶望の住人は、飢饉でなくても 1.0 にする。
- 住居（L2）: 地域に家があり、その地域の住人の数が「家の数 × 4」以下なら 0.1、そうでなければ 0.8 にする。工房・祠は屋根に数えない（2026-10-13 に決定。それまでは工房・祠を屋根とみなしていた）。
- 交流（L3）は毎年 0.2、承認（L4）は 0.1、自己実現（L5）は 0.05 増える（1.0 まで）。その年にその欲求のタスクを選ぶと 0.5 減る（0.0 まで）。

**上の段階に進める条件（指示書の食い違いの決定）**
- 文章のほうに合わせる。L1・L2 の欲求（空腹・住居）がどちらも 0.6 未満のときだけ、L3〜L5 のタスクを選べる。
- L1・L2 のどれかが 0.6 以上なら、タスクの閾値に届いていなくても、L1・L2 のうちいちばん高い欲求のタスクを選ぶ（空腹 0.7 で集会に行くことはなく、何もしないこともない）。同じ値なら空腹を先にする。

**タスクの選び方（1 年ごと）**
1. 精神崩壊中なら、崩壊の行動（下の「精神崩壊」）。
2. 空腹・住居のどれかが 0.6 以上なら、高いほうのタスク（食料を探す・屋根を探す）。
3. 交流・承認・自己実現のうち、閾値（交流 0.6・承認 0.6・自己実現 0.5）以上のもので、いちばん高いもののタスク（広場に集まる・祠で祈る・工房で研究する）。同じ値なら下の段階を先にする。今ある建物を使う（地域に祠・工房が無ければ、そのタスクは選べない）。広場の建物は無いので、交流のタスクは建物が無くても選べる（地域の中で集まる。2026-10-13 に決定）。
4. どれでもなければ、何もしない（`Idle`）。

**家（2026-10-13 に決定）**
- その年に「屋根を探す」を選んだ住人が 1 人以上いる地域に、家を 1 軒建てる。地域の番号の順に処理し、1 つの地域で 1 年に 1 軒まで。
- 建てる枠は、工房・祠と同じ選び方（2 × 2 マスがすべて草地の空き枠から、廃墟のある枠を先に、乱数で選ぶ）。寿命（200〜400 年）も同じ。乱数は住人の計算の乱数（シード・年・地域）を使う。空き枠が無ければ建たない。
- 家の種類は、建った年の地域の技術の段階（越えた閾値の数）で決め、建った後は変えない。段階 0 はわらぶき小屋（`HouseHut`）、1〜2 は木組みの家（`HouseTimber`）、3〜4 はれんがの家（`HouseBrick`）。
- 建った家は、次の年の住居と住人の上限から数える。
- 家は工房・祠と同じく、寿命で廃墟になり、150 年で地下に沈み、世界再創生でも地下に沈み、狂乱で壊される（[地層](strata.md)）。文明の計算で建て直す数（技術・文化の段階）には、家を数えない。
- 画面: 家の種類ごとの絵で描く。廃墟の上に建て増しした家は、種類にかかわらず石の土台の上の家（2 階建て、32 × 48 px）で描く。
- L3〜L5 のタスクは、今は欲求を減らすだけで、地域の技術・文化などほかの値を変えない（人が結果を変えるのは、死と精神崩壊だけにする）。2026-10-15 に、人のまとまりができたら、名のある住人は属するまとまりに小さく効くと決め直した（[住人の職業](resident-roles.md)）。M5 の今のコードは、この決め直しを入れるまで今のまま。

**体力**
- 体力（0〜100、初期値 100）は、飢饉の年に 20 減る。自閉・絶望の住人（食事を拒む）も、飢饉でない年に同じく 20 減る（2026-10-13 に決定）。それ以外の年は 10 戻る（その年の上限まで）。
- 老衰: 50 歳から、体力の上限が 1 年に 2 下がる（100 歳で 0）。
- 寒さ: 地域の気温が低い年に、防寒着の無い住人の体力が減る決まりを足す（2026-10-14 に[服装と流行](fashion.md)で決めた。まだ作っていない）。
- 体力が 0 になった住人は死ぬ。墓は地上の枠を使わず、描画だけで、その地域にしばらく（10 年）残して見せる。

**精神（SAN 値）**
- SAN 値（0〜100、初期値 100）は、毎年「カオス度 ÷ 10」減り、同じ地域の住人が死ぬと 1 人につき 10 減る。空腹が 0.6 未満の年は 5 戻る（100 まで）。住居は問わない（2026-10-13 に決定。建物がほとんど無い時代に SAN 値が戻らず、カオス度のドグマで全員が同じ年に崩れて狂乱が重なり、星の崩壊が 3〜5 倍早まったため）。
- 予言者の狂気は、住人の SAN 値とは分ける（予言者は住人ではない。[AI による表現](ai-presentation.md)の未決のまま）。

**精神崩壊**
- SAN 値が 0 になった年に、シードを指定した乱数で、狂乱（`Rampage`）か自閉・絶望（`Catatonia`）のどちらかになる（半分ずつ）。異端の教祖（`CultLeader`）は、人が唱えるドグマを決めるまで作らない（指示書の食い違い「異端の教祖の行動」は、そのときに決める）。
- 狂乱: 崩壊した年に、同じ地域の建物を 1 つ（乱数で選ぶ）その年の廃墟にする（[地層](strata.md)の老朽化と同じ扱い）。カオス度は上げない（2026-10-13 に決定。当初は 1 人 5 上げていたが、狂乱 → カオス度の上昇 → SAN 値の低下 → 狂乱が止まらず、住人が 500 人ほどになると、ドグマが無くてもカオス度が 100 に張り付いたため）。
- 自閉・絶望: 食事を拒む（空腹が 1.0 になる）。
- 崩壊は 3 年続き、その後 SAN 値 30 で戻る。崩壊中に体力が 0 になれば死ぬ。

**乱数**
- 住人の計算の乱数は、建物の乱数と同じく「シード・年・地域」から作り、地域の中では ID の小さい住人から順に使う。住人を足しても、ほかの地域の結果は変わらない。
- 名前の乱数は「シード × 住人の ID」から作る別の乱数とする（上の案のとおり）。

**1 年の中の順番**（地層の計算の後。星が崩壊した年には計算しない）
1. 移り住む（正常な大人が 2 人より少ない地域に 1 人）。
2. 欲求を動かす。
3. 体力・SAN 値を動かし、体力 0 の住人を死なせる（死んだ住人の地域の SAN 値をまとめて減らし、パートナーを独身に戻す）。
4. SAN 値 0 の住人を精神崩壊させ、崩壊が終わった住人を戻す。
5. タスクを選び、狂乱の行動と、選んだタスクの欲求の減りを当てはめる（子供は何もしない）。
6. 屋根を探す住人のいる地域に家を建てる。
7. つがいから子供が生まれる。
8. 独身の大人がつがいになる。
9. 年数のたった墓を消す。

**名前と称号**
- コアは、名と家名を「音のパーツの ID」（例: `NAME_PREFIX_ART`・`NAME_SUFFIX_ORIUS`）で、称号を称号の ID（例: `EPITHET_BUILDER`）で持つ。表示するときは、接頭辞と接尾辞の組み合わせごとに翻訳ファイルに置いた表記（キー `NAME_ART_ORIUS` → 日本語 アルトリウス、英語 Artorius）を引く。パーツをそのまま連結すると、つなぎ目の音が重なる（アルト ＋ トリウス ＝ アルトトリウス）ため（2026-10-13 に決定。組み合わせ 36 通りの読みは AI が英語の綴りから書いたもので、直してよい）。「名・家名 の 称号」の語順は翻訳ファイルの書式で決める（日本語 `{0}・{1} の {2}`、英語 `{0} {1} the {2}`）。

- 種族ごとのパーツの組（陸の人・海底人）だけを使い、地域の文化の値は名前に効かせない。
- 移り住んだ住人は家名を新しく作る。親の家名の引き継ぎ（どちらの親か、半魚人のパーツ）は、世代交代を作るときに決める。
