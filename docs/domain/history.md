## 目的

ドグマの誕生・住人の狂乱・称号を持つ住人の死・星の崩壊が、年ごとに積み重なっていくのを、プレイヤーが後から読み返せるようにする（アクアリウムとして歴史を鑑賞する）。

## ゲームのルール

用語は [用語集](glossary.md) に合わせる。

- 年表はコアが持ち、決定的に積む。表示の文は翻訳ファイルで組み立てる（AI による神話化は後に回す）。
- 年表に残す出来事（仮）:

  | 出来事 | 残す項目 | いつ |
  | :--- | :--- | :--- |
  | ドグマの誕生 | 記号・ドグマの種別・予言者が誤解して語った神託の文（AI が作れたときだけ。後から添える。[AI による表現](ai-presentation.md)） | 神託でドグマが一覧に加わったとき（その時の年） |
  | 住人の精神崩壊 | 名前・称号・崩壊の種類 | 住人の 1 年の計算で精神崩壊したとき |
  | 称号を持つ住人の死 | 名前・称号 | 称号を持つ住人が死んだとき。称号の無い住人の死は残さない（数が多く、年表が埋もれるため） |
  | 星の崩壊 | なし | 跳躍・1 年の進みで星が崩壊した年 |
  | 世界再創生 | なし | 世界再創生をしたとき（再創生する前の年） |

  - 移り住む・生まれる・つがいになる は、数が多いので残さない。家系図は構想「歴史の全書と博物館」で作る。
- 1 年の中の順番: 住人の出来事（住人の計算の中で起きた順）→ 星の崩壊。ドグマの誕生は神託を下したときに足す。
- 世界再創生をしても年表は消さない（星の歴史として周回をまたいで残す）。年は再創生で 0 に戻るので、年表の年は周回ごとに 0 から数え直しになる。境目は「世界再創生」の行で見分ける。
- 年表の行の数には上限（200 行）があり、超えたら古い行から消す。
- 年表はセーブに残す（`saveVersion` 10）。
- 章: 年が 100 の倍数になったら、今の章を閉じて「章の終わり」の行を足す（年・始まりの年・始まりと終わりのカオス度。仮）。星の崩壊は崩壊の行の後で、世界再創生は再創生の行の前で閉じる。章の始まりは年表と一緒にセーブする。神話の文は [AI による表現](ai-presentation.md) の「歴史の神話化」で後から添える。

### 新しい星での年表（2026-10-16 に決定。上の決まりは、住人が数十人の今の星のもの）
人のまとまり・96 地域・およそ 1 万年の歴史（[歴史の長さと時間の速さ](time-scale.md)）に合わせて、次のように読み替える。切り替えるのは、新しい星をゲームにつなぐ段から。
- **残す出来事は、知らせの段階で決まる**: 「止める」と「手紙」の段階の出来事を残し、「流れ」は残さない（[出来事の知らせ](notifications.md)。2026-10-15 に決定済み）。段階は、プレイヤーの設定で変える前のもの。上の表の「住人の精神崩壊」「名のある住人の死」なども、この段階の表に入れて決める。
- **年は続けて数える**: 世界再創生はなくなり、年は崩壊をまたいで続け、人の世の番号を持つ（[星の崩壊と文明の崩壊](collapse.md)。2026-10-15 に決定済み）。上の「年は再創生で 0 に戻る」は使わない。
- **止める行は消さず、手紙の行は章にたたむ**: 「止める」の段階の行（神の目覚め・予言者の死・奇跡・文明の崩壊など）は消さない。「手紙」の行は 1,000 行（仮）まで残し、超えたら古い章の行から、その章のまとめの 1 行（「この章で戦 12・飢饉 3」のような数）にたたむ。細かい出来事は、知らせの「出来事の記録」（直近 1,000 件）で読む。上の「200 行・古い行から消す」は使わない。
- **章は大きな変化で区切る**: 予言者の代替わり・神の眠りと目覚め・人の世の変わり目・星でいちばん大きな国の交代で、章を閉じる（王朝や時代で区切る歴史書のように）。何も起きなければ 500 年（仮）で閉じる。章の名前は、その章の予言者や国の名から付ける（神話の文は [AI による表現](ai-presentation.md)）。上の「年が 100 の倍数で閉じる」は使わない。
- **読み方**: 年表の欄で、章・地域・国・宗派・人で絞り込める（Dwarf Fortress の Legends）。行を押すと、その地域へカメラが動く（知らせと同じ。[カメラの視点](camera-views.md)）。スマホでも年表を読める（[通信の契約](../protocol/messages.md)が変わる）。

### 画面
- HUD のボタン「年表」で、年表の欄を開け閉めする。欄には新しい行を上にして「{年} 年　{出来事}」の形で並べ、スクロールできる。ドグマの行に神託の文があれば、見出しを「」で添える。
- 章の行は「{始まり}〜{終わり} 年の章」の形で出す。神話の文がある章は、見出しを「」で添えた行を押すと、本文が下に開く（もう一度押すと閉じる。開き閉めは画面だけの状態で、セーブしない。2026-10-13 に決定）。神話の文が無い章は、カオス度の変化（始まり → 終わり）を添える。
- 欄は開いているあいだ、行が増えたら組み立て直す。

### 未決だったことの決め方（2026-10-17 に AI の推奨で決め、人間が一覧で確認した）
- **星でいちばん大きな国の交代**: 人口がいちばん多い国が変わった年に残す。
- **章の名前とまとめの行**: 章の名前は、LLM が書く章の神話の見出しを使う。LLM が無ければ「第 N 章（〇〇年〜）」にする。
- **今のセーブの年表からの切り替え**: 変換しない。セーブの版を上げたら、古い年表は持ち越さない（[ロードマップ](../roadmap.md)の「古いセーブは読めなくてよい」）。
- **欄と文**: 欄は今の HUD の右の欄のまま。1 行は「〇〇年 出来事」の形にする。
- **スマホ**: 知らせの段階（止める・手紙）で絞り込める。メッセージの形は、通信の契約（[messages.md](../protocol/messages.md)）を書くときに決める。
