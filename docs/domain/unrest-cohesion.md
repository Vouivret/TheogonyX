## 目的

カオス度と調和度に、現実の社会に寄せた意味を持たせる。カオス度は地域の**不穏**（恐れ・暴力・無秩序）、調和度は地域の**結束**（信頼・まとまり）とする。どちらも人の暮らし・信仰・出来事で動き、人を通して効く。危機で結束し、栄えて緩み、崩れる、という文明の盛衰の巡りが、決まりを足さずに仕組みから出てくるようにする。

## ゲームのルール

用語は [用語集](glossary.md) に合わせる。量はすべてデータ定義（`rules.json`）に置く仮の値にする。

### 意味（2026-10-15 に決定）
- **カオス度**（`ChaosLevel`、0〜100）: 地域の不穏。恐れ・暴力・無秩序の度合い。
- **調和度**（`HarmonyLevel`、0〜100）: 地域の結束。人どうしの信頼とまとまりの度合い（Turchin のアサビーヤ）。
- どちらも地域ごとの値（[地域の環境](regional-environment.md)）。星の崩壊の条件には使わない（[星の崩壊と文明の崩壊](collapse.md)）。

### カオス度が上がる元（案）
- 飢饉・疫病・災害・戦（[住人による森と水の利用](resource-use.md)・[疫病](plague.md)・[気候と天候](weather.md)・[地域間の戦争](warfare.md)）。
- 矛盾する信仰を持つ人が同じ地域に混ざる（同じ記号の崇拝と破壊など。[宗教](religion.md)）。
- 違うドグマの聖地の重なり（[聖地](holy-site.md)。決定済み）。
- 雷の奇跡（[奇跡](miracle.md)。決定済み）、汚染ルーン（[神託のデッキ](oracle-deck.md)。決定済み）。
- 人口の圧力: 地域の人口が、養える人数を超える（[人の数](population.md)。Turchin の構造人口学）。
- 闘技場と賭博（[娯楽](entertainment.md)）。
- 狂乱した住人は、カオス度を上げない（2026-10-13 の決定のまま。[人の欲求と健康](agent-needs.md)）。

### カオス度の落ち着き方（2026-10-15 に決定）
- 毎年、今の値の決まった**割合**が減る（例: 半分になるまでおよそ 10 年）。高いときは速く、低いときはゆっくり落ち着き、上がり続けて張り付くことが起きにくい。
- 調和度が高いほど、減る割合を大きくする（結束した社会は早く立ち直る）。
- 今の「毎年 0.2 ずつ減る」（[時代跳躍](time-skip.md)）から、いつ切り替えるかは未決。

### 調和度が上がる元・下がる元（案。緩むことは 2026-10-15 に決定）
- **上がる**:
  - 地域の人の中で、同じ信仰（宗派）の人の割合が高い（[宗教](religion.md)）。
  - 祭り・祈り（[宗教](religion.md)の儀礼）、徒競走・力比べ（[娯楽](entertainment.md)の土）。
  - 共通の危機や外敵を、一緒に乗り越える（飢饉・災害・戦のあと、人が残った地域。Turchin の「辺境で結束が生まれる」）。
- **緩む**（2026-10-15 に決定）: 長い平和と豊かさで、ゆっくり下がる（Turchin の「中心では結束が失われる」）。[信仰と世俗化](secularization.md)の「豊かさで信仰が薄れる」と同じ向き。

### 効く先（案）

| 値 | 効く先 |
| :--- | :--- |
| カオス度 | 住人の SAN 値の減り（今の「カオス度 ÷ 10」のまま、住人のいる地域の値）。群衆の狂乱（地域ごとの値で判定）。逃げ出す人（隣の地域へ移り住む）。生まれる数が減り、死ぬ数が増える。発明を失いやすい（[発明の木](invention-tree.md)）。信仰が強まる（危機。[信仰と世俗化](secularization.md)）。地域の文明の崩壊のきっかけ（[星の崩壊と文明の崩壊](collapse.md)） |
| 調和度 | カオス度を早く落ち着かせる。災害・飢饉で人が散らばりにくい。ほかの宗派への改宗に抵抗する。戦の士気（[地域間の戦争](warfare.md)）。国の広がりと、割れにくさ（[国と集落](polity.md)） |

### 盛衰の巡り（2026-10-15 に決めた仕組みから出てくるもの）
1. 危機を乗り越えた地域は、結束が強まる。
2. 結束した地域は、不穏が早く落ち着き、人が増え、広がる。
3. 長い平和と豊かさで、結束が緩む。人が増えて、人口の圧力で不穏が溜まる。
4. 緩んだ地域は、次の危機で不穏が落ち着かず、人が逃げ、文明が崩れやすい。崩れたあとに残った人が、また結束する。
- この巡りのための決まりは足さない。上の上がる元・下がる元・効く先から出てくるに任せる。

### 決定性の境界
- カオス度と調和度の計算は、乱数を使わない（逃げ出す人の選び方など、効く先で乱数を使うものは、それぞれの仕様のシードを指定した乱数）。同じシード・同じ入力からは同じ値になる。
- 全地域を、前の年の値から同時に計算する（並べ方で結果が変わらない）。

## 対象外

- カオス度に、超自然の淀み（狂気・変異）の意味を持たせること（2026-10-15 に、不穏と結束にすると決めた）。
- カオス度の限界での、星や地域の直接の崩壊（[星の崩壊と文明の崩壊](collapse.md)）。
- 狂乱した住人がカオス度を上げること（2026-10-13 の決定）。
