# 仕様書: 星の表示（地表タイルと HUD）

- テスト仕様書: [docs/test/planet-display.md](../test/planet-display.md)
- 関連ADR: なし
- 通信: なし
- 画面デザイン: なし。アセットと画面の規格は [docs/art-guide.md](../art-guide.md)
- 出典: 2026-10-11 のチャットでの確定仕様案（ロードマップ M1「画面の視覚化」）

## 目的

ログでしか見えなかった星の環境を、地表のタイルと HUD で画面に描き、神（プレイヤー）がドグマの影響を眺めて楽しめるようにする。

## ゲームのルール

用語は [用語集](glossary.md) に合わせる。

### タイル種別の判定

世界の状態（`WorldState`）から、地表のタイル種別を決める。上の行から順に調べ、最初に当てはまった種別にする（上位の条件に当てはまったら、下位は調べない）。

| 優先度 | タイル種別 | 条件 | 見た目 |
| :--- | :--- | :--- | :--- |
| 1 | 氷河 | 気温 ≤ 0.0℃ | 氷と雪で覆われた白い大地 |
| 2 | 焦土 | 気温 ≥ 50.0℃ | ひび割れた黒ずんだ大地（マグマの照り返し） |
| 3 | 砂漠 | 水資源 ≤ 20.0 | 黄色・茶色の不毛な砂漠 |
| 4 | 密林 | 森林量 ≥ 70.0 | 鬱蒼とした濃い緑 |
| 5 | 草地 | 上のどれにも当てはまらない | 標準的な緑の草地 |

- 判定は、画面を更新するたびに行う（自動進行では1年ごと、100年跳躍では跳躍が終わった後。[時間の進め方](time-control.md)）。
- 閾値は、実装時にゲームデータ定義（`game/data/`）へ移す。
- 世界の初期値（森林量 100、水資源 100、気温 15℃）は密林になる。

### マップ

- 地表は横 16 × 縦 9 タイル（1タイル 16×16 px、全体で 256×144 px）。
- 上の判定で決めたタイル種別（最も支配的な環境の異常）を、悪化の度合いに応じた列数だけ、左（西）の列から塗る。残りの右側の列は草地にする。
- 塗り方は列ごとに決め、縦の9行は同じ列なら同じタイル種別にする。
- 列数は次の式で求める。「四捨五入」は小数点以下が 0.5 ちょうどのとき切り上げる。

| タイル種別 | 列数 |
| :--- | :--- |
| 氷河 | (0 − 気温) ÷ 50 × 16 を四捨五入し、1〜16 に収める（0℃ で 1列、−50℃ で 16列） |
| 焦土 | (気温 − 50) ÷ 30 × 16 を四捨五入し、1〜16 に収める（50℃ で 1列、80℃ で 16列） |
| 砂漠 | (100 − 水資源) ÷ 100 × 16 を四捨五入し、1〜16 に収める（水資源 20 で 13列、0 で 16列） |
| 密林 | (森林量 − 70) ÷ 30 × 16 を四捨五入し、1〜16 に収める（森林量 70 で 1列、100 で 16列） |
| 草地 | 0列（16列すべて草地） |

### HUD

画面の隅に、次の4つを表示する。

- 年: 「創世紀 {年} 年」（例: 年 0 なら「創世紀 0 年」）
- カオス度: 小数第1位まで、% を付ける（例: 「カオス度 12.5%」）。1年ごとの小さな変化が見え、桁が多すぎない
- 調和度: カオス度と同じ形（例: 「調和度 50.0%」）
- 現在のドグマの一覧（対象の記号と種別）

文言は翻訳ファイルに置く（`.agent/rules/ui.md`）。
