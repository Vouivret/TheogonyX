## 目的

神託を、**読めない文字を読み解き、その文字で書いて伝える遊び**にする。

- 今の神託（方言の聞き違え）は、ずれ表を覚えれば解ける固定の暗号で、方言帳が埋まると遊びが終わる。
- 文字は、(1) 神も人の文字を最初は読めない、(2) 時代と地域で崩れ・分かれる、(3) 地層の碑文に昔の字が残る、の 3 つで、星ごと・時代ごとに読み直しが続く。
- 「人が神の意図を取り違える」芯は残す。取り違えは、字の部品の組み違い・崩れた字の読み違いとして起きる。参考: 『Chants of Sennaar』（文脈から文字を解読する遊び）。

## 確認したこと（2026-10-17）
- 字を部品（意味・働き・飾り）の組み合わせにする。
- 手帳は神が自分で書き込み、正解は見せない。
- 自由文の神託はやめる。
- 小さく試す範囲は、今の小さな星のまま、1（字のしくみ）・2（読む。2.1 の刻まれた字を含む）・3（書く）・4 のうち崩れ 1 段まで。5（碑文を掘る）は後。
- 人間が足した: 世界の中に字が刻まれていて、そこから意味を推測できる（2.1）。

## ゲームのルール（AI の推奨。上の「確認したこと」のほかの細部は、人間が一覧で確かめる）

用語は [用語集](glossary.md) に合わせる。新しい用語の案は「未決」の末尾。

### 1. 字のしくみ（星ごとにシードで作る）
- **字は部品の組み合わせ**: 1 字は、**意味の部品**（何について。記号ごとに 1 つ: 木・水・火・土・金・血。後で人・知を足す）と、**働きの部品**（どうする。崇拝・禁忌・破壊の 3 つ）を組んだもの。漢字の偏とつくりに寄せる。
- **飾りの部品**（任意）: 否定・強め・方角（東・西）・数（多い）の 4 つ。字の外側に付ける。最初の試しでは方角（東・西）だけを入れる（plan）。
- **形はシードで作る**: 部品の形は、星のシードから、少ない画（線・弧・点）を組んで作る（3〜6 画）。似た形の部品が 1〜2 組できるように作り、読み違いの元にする（下の 4）。部品の数は少なく保つ（意味 6・働き 3・飾り 4 の 13 個）。
- **並び方の決まり**もシードで決める: 意味の部品を左に置くか上に置くか（働きの部品は反対側、方角の部品は字の下）。同じ部品でも、星ごとに字の見た目が変わる。
- 絵は、部品をベクターの線で描き、ドット絵の画面に合わせて太らせる（アセットは要らない）。

### 2. 読む（祈りが字で届く）
- 祈り（[予言者の依頼](prophet-request.md)・日々の祈り）は、人の字の **2〜4 字の列** で届く。今の吹き出しの文の代わり。
- 祈りの字は、その時の世界から決まる（例: 渇きの依頼なら「水」の意味の部品＋「欲しい」に当たる働き、森の破壊の教えが広まっていれば「木」＋「破壊」）。**同じ状況では同じ字が出る**ので、状況と字を見比べて意味を推理できる。
- 神は **字の手帳** に、部品ごとに自分の推理（どの意味か）を書き込む。正解は見せない。書き込みは自由で、間違っていてもよい。
- 推理の手がかり: 祈りが来たときの世界の値・景色（干ばつ・森の減り）・年表の出来事。手帳の部品を押すと、その部品が出てきた祈りの一覧（年と状況つき）を見られる。
- **答え合わせは自動で付けない**: 手帳に「確か」の印は付けない。神託を下した後に、人の動きと、世界に新しく刻まれる字（2.1）を見て、自分で当たり外れに気づく。

### 2.1 世界に刻まれた字（2026-10-17 に人間が足した）
人は、暮らしに関わる物に字を刻む。刻まれた物そのものが、字の意味の手がかりになる（『Chants of Sennaar』の、物のそばの看板から読み解くのと同じ）。
- **地形の目印**: 湖の岸の石に「水」、森の入り口の杭に「木」、焚き火の炉に「火」、畑の境に「土」、工房の前に「金」。意味の部品だけの字（働きの部品なし）で、そこにある物を指す。祈りより先に見つかる、最初の手がかり。
- **建物の札**: 祠には、その地域でいちばん多く信じられている教えの字（意味＋働き。例: 木＋崇拝）。工房には「金＋崇拝」、家には「土」（地域ごとにいちばん古い家にだけ。2026-10-17 に遊んで、全部の家に刻むと地表が札で埋まったため）。
- **禁忌の札**: 禁忌を信じる人が多い地域には、その記号の物のそばに「記号＋禁忌」の札が立つ（例: 森のそばに 木＋禁忌）。破壊の教えが広まった地域には、壊された物の跡に「記号＋破壊」が残る。
- **墓**: 死んだわけ（飢え・渇き・争い・狂乱）に当たる字（例: 飢え → 木＋否定、争い → 血）。
- **見え方**: 刻まれた字は、地表の物の上に小さな印で出る。印を押す（スマホではタップ）と、拓本の欄に大きく出て、その字が刻まれた物と場所・年が並ぶ。拓本の欄から、字の部品を手帳に写して、推理を書き込める。
- **教えの結果が字で見える**: 神託を下した後、人が教えをどう読んだかは、祠の札・禁忌の札・壊された跡の字として世界に現れる（例: 「木＋崇拝」と書いたのに、森のそばに「木＋破壊」の跡が増えた → 働きの部品の推理が違っていた）。これが答え合わせになる。
- **字の時代が残る**: 刻まれた字は、刻んだ時代の形のまま残る。古い建物・墓の字は、崩れる前の形をしている（4 の崩れの手がかり）。建物が廃墟になって沈むと、碑文と同じく地層に残る（5）。

### 3. 書く（神託を字で下す）
- 神託は、手帳の部品を選んで **1 字〜3 字** を組んで下す（例: 「木＋崇拝」「水＋破壊＋否定」）。字の組み方（並び方の決まり）も合わせないと、読めない字になる。
- 予言者（と人）は、その字を **自分の文字の決まりで読む**。教えは、読んだ字の意味の部品（記号）× 働きの部品（種別）。飾りは強度と行き先に効く（否定は種別を禁忌に寄せる、強めは強度を上げる、方角は予言者の行き先）。
- **読み違い**は、組み違いと崩れから起きる:
  - 並び方の決まりと違う字は、部品の場所が入れ替わって読まれる。意味の場所に働きの部品が来れば謎の字になる（2026-10-17 に plan で決めた。「形のいちばん近い字に読む」をやめた）。
  - 似た形の部品は、時代が下るほど混ざって読まれやすい（下の 4）。
  - 読めない字（近い字が無い）は、謎の字として経典にだけ残り、教えにはならない。
- 神威の代償・歪み・依頼が済むこと・予言者の告げる吹き出し（掟の 1 行）・信者の広がりは、今の神託のまま使う。告げる吹き出しには、人が読んだ字と、その読み（神の言葉に直した意味）を出す。
- LLM は飾りに回す: 解読が進んだ（手帳の推理が「確か」になった）字の祈りを、詩の訳文として添える。計算には使わない。

### 4. 字が崩れる・分かれる（時代と地域）
- **崩れ**: 何十年かごとに、字の部品が少しずつ略される（画が減る・つながる）。崩れた後の祈りは新しい形で届き、手帳の絵は古いままなので、照らし合わせ直しになる。崩れは決まった順（シードで決めた略し方）で進み、同じシードなら同じ崩れ方になる。
- **似た形が混ざる**: 崩れが進むと、似た形の 2 つの部品が同じ形になる時代がある。その時代は、神がどちらを書いても人はどちらか一方に読む（読み違いの元）。神は飾りの部品で区別する工夫が要る。
- **分かれる**: 言葉が分かれた地域（[文化の種類](culture-kinds.md)の言葉の分かれ）は、字も別の崩れ方をする。予言者がその地域へ旅すると、そこの字で祈る。手帳は文字ごとに分ける。
- 小さな MVP では、地域の分かれは入れず、崩れだけを入れる。
- 崩れた後も、古い建物・墓に刻まれた字は古い形のまま残るので、新しい形と古い形が世界に並ぶ。両方を見比べて、どの部品がどう略されたかを推理する。

### 5. 碑文を掘る（地層）
- 神託を下すと、予言者の地域に **碑文**（その時の字で書いた神託）が残る。建物と同じく、年月で廃墟になり、地層に沈む（[地層](strata.md)）。
- 地層を見ると、昔の碑文を読める。昔の字の形で書いてあるので、今の手帳では読めない字がある。崩れの前の形を思い出す・推理する遊びになる。
- 碑文を読むと、自分の昔の神託が人にどう読まれたか（その時の教え）が分かる。年表に「〇〇年の碑文は『木を崇めよ』と読まれていた」と残る。

### 6. 今の小さな MVP から残すもの・替えるもの
| 今のもの | どうするか |
| :--- | :--- |
| 自由文の神託・LLM の聞き取り | やめる（LLM は祈りの詩の訳だけに使う） |
| 語義のずれ表・器の段 | やめる（読み違いは字の組み違いと崩れから起きる） |
| 方言帳 | 字の手帳に作り替える（自動で埋まる欄 → 神が自分で書き込む欄） |
| 建物・墓・地形（湖・森・焚き火） | 字を刻む場所にする（2.1） |
| 手札（予言者の語彙） | 予言者が知っている字（記号）に読み替える。知らない記号の字は読めない（謎の字） |
| 祈り（知っている名詞を入れる） | 字の列で届く祈りに作り替える |
| 神威・歪み・依頼・信仰の広がり・予言者の旅・セーブの土台 | そのまま使う |
| 神託の記録（経典の元） | 神が組んだ字と、人の読みを残す。碑文の元にもする |

## 対象外

- 音（読み方・発音）。字は意味だけを表し、音は持たない（多言語で同じ遊びになるように）。
- 地域ごとの字の分かれ（小さな MVP の後。[文化の種類](culture-kinds.md)の言葉の分かれと一緒に入れる）。
- スマホで字を組む画面（PC で遊びを確かめてから）。

## 未決（人間が決める・遊んで決める）

- **方向の確認**: 上の 1〜6 の推奨でよいか。特に、(a) 字を部品の組み合わせにすること、(b) 手帳は神が自分で書き込み、正解は見せないこと、(c) 自由文の神託をやめること。
- **小さく試す範囲**: 2026-10-17 に決めた（上の「確認したこと」）。2.1 の刻まれた字のうち、どれから入れるか（AI の推奨: 地形の目印・祠の札・禁忌の札を先に、墓と壊された跡は後）。
- 部品の数（意味 6・働き 3・飾り 4）と画の数（3〜6 画）、似た形の部品の組の数。
- 祈りの字の数（2〜4）と、状況から字を決める表（困りごと・広まった教え・出来事ごとに、どの部品を使うか）。
- 崩れの間隔（何十年ごとか）と段の数。似た形が混ざる時代の長さ。
- 刻まれた字の数と間隔（地形の目印をいくつ置くか、札が書き換わる速さ）。拓本の欄の見せ方と、手帳に写す操作。
- 墓の死因の字の表（飢え・渇き・争い・狂乱 → どの部品か）。
- 碑文の残り方（建物と同じ寿命か）と、地層の画面での読み方。
- 用語集に足す案: 字（Glyph）・部品（Radical）・字の手帳（Glyph notebook）・崩れ（Script decay）・碑文（Inscription）・刻まれた字（Carved glyph）・拓本の欄（Rubbing panel）・謎の字（Unknown glyph）。
