## 目的

96 の地域で並行して起きる出来事（戦・飢饉・疫病・発明・王の死・宗派の分裂など）を、見逃さず、しかし埋もれないようにプレイヤーへ知らせる。神に関わる大事なことだけで時間を止め、それ以外は重さに応じて手紙・流れ・地図の印で見せる。

## ゲームのルール

用語は [用語集](glossary.md) に合わせる。

### 知らせの 3 つの段階（2026-10-15 に決定）

| 段階 | 見せ方 | 例（案） |
| :--- | :--- | :--- |
| 止める | 時間を止め、画面の中央に大きく出す | 予言者の依頼（今のまま）・奇跡の力が満ちた・神の目覚めと眠り・予言者の死と後継・神の宗派の分裂 |
| 手紙 | 時間は止めず、画面の端にカードとして積もる。読むと消える | 戦の始まりと終わり・王の死と継承の争い・大きな疫病や飢饉・発明・聖地ができる |
| 流れ | 年表と、小さく流れる告知だけ | 小さな襲撃・小さな集落の誕生・遠い国の出来事 |

- 出来事の種類ごとの既定の段階は、データ定義の表に置く。

### 選び方（2026-10-15 に決定）
- 既定の段階に、**神との関わり × 大きさ**を足して、出す段階を決める。
  - 神との関わり: 神の宗派・信者の多い地域・予言者・聖地に関わる出来事ほど上の段階に上がる。
  - 大きさ: 死んだ人数・被害・関わる人口が大きいほど上がる。
  - 信者のいない遠い国の小さな戦は、流れに回る。
- 同じ種類の出来事が同じ年に重なると、1 つにまとめる（例:「3 つの地域で飢饉」）。

### プレイヤーの設定（2026-10-15 に決定）
- 設定の画面で、出来事の種類ごとに「止める・手紙・流れ・出さない」を変えられる（Stellaris のように）。
- 予言者の依頼は「止める」のまま変えられない（[予言者の依頼](prophet-request.md)）。
- 設定は表示だけのもので、計算の結果は変わらない。

### 知らせからできること（2026-10-15 に決定）
- **その場所へ飛ぶ**: 知らせを押すと、カメラがその地域へ動く（[カメラの視点](camera-views.md)）。
- **地図に印を残す**: 戦・疫病・飢饉など続いている出来事は、星の地図のその地域に小さな印（剣・髑髏・空の器など）を出し続ける。引いた視点で、今どこで何が起きているかが一目で分かる。
- **スマホに送る**: 「止める」の知らせを、コンパニオン（スマホ）にも送る。現実同期で PC を見ていないときに気づける。通信の契約（[messages.md](../protocol/messages.md)）が変わる。

### 手紙の上限・記録・設定の置き場所・スマホ（2026-10-15 に決定）
- **手紙の上限**: 画面に積もる手紙は、最大 8 枚（仮の値）。超えたら、いちばん古くて段階の軽い手紙から流れに回す。決まった年数（仮 100 年）読まれない手紙も、流れに回す。長い跳躍や自動進行で画面が埋まらないようにする。
- **年表と出来事の記録**:
  - [星の年表](history.md)（上限 200 行）には、止める・手紙の段階の出来事だけを残す（星の歴史の物語）。
  - 流れを含むすべての出来事は、別の「出来事の記録」に、直近の決まった数（仮 1000 件）だけ残す。種類・地域で絞り込める（Dwarf Fortress）。押すと、その地域へ飛ぶ。
  - 年表に残すかどうかは、プレイヤーの設定の前の段階（既定の段階 ＋ 神との関わり × 大きさ）で決める。設定を変えても、年表の中身は変わらない。
- **設定の置き場所**: 種類ごとの段階の設定は、ゲーム全体で 1 つにし、すべての星で共通にする（Stellaris・Crusader Kings 3）。星のセーブとは別の設定のファイルに置き、セーブの形は変えない。
- **スマホ**:
  - 送るのは「止める」の知らせだけ。
  - 予言者の依頼は、今までどおりスマホから神託で答えられる。奇跡の力が満ちた知らせからは、その場で奇跡を落とせる（[奇跡](miracle.md)）。それ以外の知らせは、読めば消える。
  - 同じ種類の知らせは、決まった間（仮 1 分）に 1 回までにまとめて送る。

### 決定性の境界
- 知らせは、コアが決めた出来事を見せるだけ。どの段階で見せるか・設定・スマホへの送信は、計算の結果に影響しない。
- ただし「止める」は時間の進みを止めるので、プレイヤーの入力の時刻に関わる（入力の並びとして記録すれば、同じ結果になる。今の依頼と同じ）。

## 受け入れ条件

値が決まってから足す。今は値に関わらない形だけを置く。

| ID | Given（前提） | When（操作） | Then（結果） |
| :--- | :--- | :--- | :--- |
| AC-notifications-001 | 自動進行中 | 奇跡の力が満ちる | 時間が止まり、知らせが中央に出る |
| AC-notifications-002 | 同じ種類の出来事（飢饉）が、同じ年に 3 つの地域で起きる | その年を計算する | 知らせは 1 つにまとまり、3 つの地域が分かる |
| AC-notifications-003 | 同じ大きさの戦が、信者の多い地域と、信者のいない地域で起きる | 知らせの段階を求める | 信者の多い地域の戦のほうが、上の段階になる |
| AC-notifications-004 | 設定で、ある種類を「出さない」にした | その種類の出来事が起きる | 知らせは出ないが、年表には残り、計算の結果は設定の前と同じ |
| AC-notifications-005 | 手紙の知らせ | 押す | カメラがその地域へ動く |
| AC-notifications-006 | 予言者の依頼 | 設定で段階を変えようとする | 変えられない（止めるのまま） |
| AC-notifications-007 | 画面に手紙が上限の枚数ある | 新しい手紙の出来事が起きる | いちばん古くて軽い手紙が流れに回り、手紙の枚数は上限のまま。回された出来事は記録に残る |
| AC-notifications-008 | 流れの段階の出来事 | その年を計算する | 年表には残らず、出来事の記録に残る |

## 対象外

- 知らせの設定で、計算の結果を変えること（表示だけ）。

- スマホへのメッセージの形（[messages.md](../protocol/messages.md)）と、スマホで奇跡を落とす操作。間引く間の値（仮 1 分）。
- 出来事の記録を星のセーブに入れるか（入れればセーブの形が変わる）。
- 設定のファイルの置き場所と名前。
