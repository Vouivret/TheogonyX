## 目的

住人の服を、気候・材料・身分・仕事で決まる実用のものにし、その上に地域ごとの流行を重ねる。画面を引いて見ただけで、どの地域が寒く、豊かで、危うく、何が流行っているかが分かるようにする。

## ゲームのルール

用語は [用語集](glossary.md) に合わせる。

### 方針（2026-10-14 に決定）
- **実用がメイン**: 服は、気候・手に入る材料・身分・仕事で決まり、見た目と、寒さ・汚れからの守りに効く。
- **流行は見た目と承認**: 流行は、色と形の見た目を変える。流行の服を着ることは、承認（L4）の欲求を満たす行いの一つにする（今の「装飾品を作る」と同じ位置）。
- **流行遅れで SAN 値は下げない**: SAN 値を下げる元を増やさない（狂乱 → カオス度 → SAN 値 → 狂乱の止まらない輪のようなことを起こさないため。[人の欲求と健康](agent-needs.md)）。

### 実用の服（案）
住人の服は、次の順で決まる。
1. **素材**: 地域で手に入る素材（[文化の種類](culture-kinds.md)の「衣服と布」。毛皮・樹皮・毛織物・麻・綿・絹）。動物・作物（[自然の種類](natural-kinds.md)）と交易で決まる。
2. **形**: 地域の気温で決まる（寒いほど厚く重ねる、暑いほど薄く短い）。
3. **身分と仕事**: 仕事着（農夫・漁師・技師・司祭など。[住人の職業](resident-roles.md)）、豊かな人の上等な服（絹・染め物・飾り）、貧しい人のつぎはぎのぼろ布（構想「階級と貴族」）。
4. **守りの服**: 寒さの厳しい年の防寒着、大気汚染の地域の布頭巾・マスク（[大気汚染](air-pollution.md)ができてから）。

### 寒さと体力（2026-10-14 に決定）
- 地域の気温が低い年（閾値は仮の値）、防寒着を着ていない住人は体力が減る。防寒着を着ていれば、減らないか、少ししか減らない。
- [気候と天候](weather.md)の「天候は住人の体力を直接減らさない」を、寒さの分だけ改める（寒さは天候でなく、その年の地域の気温で判定する）。

### 流行の生まれ方（案）
- 次のときに、乱数で（シードを指定した乱数）、地域に新しい流行（色と形の組）が生まれる。
  - 文化の値（`CultureVector`）の高い地域で、毎年まれに。
  - 流行を生む人がいるとき（吟遊詩人・貴族。それぞれの仕組みができてから）。
  - 神託が下ったとき: 神託の記号の色・形が、予言者のいる地域の流行になる（火 → 赤と熱帯風、金 → 金属の飾り、水 → 青と流れる布、木 → 緑と植物の模様、土 → 黄土色と厚手の布、穢れ → 黒と赤。表はデータ定義に置く）。
- 流行は、色（パレット）と、形のパーツ（帽子・上着・飾り）の組で表す。

### 流行の伝わり方（案）
- 流行は、人の交わりで隣の地域へうつる: 移住・巡礼・交易・交通（[交通](transit.md)・[運送と物流](logistics.md)）。
- **言葉が違う地域への伝わり方**: 言葉の系統が違う地域へうつるときは、乱数で形や色が少し変わる（読み違えた流行）。ずれが大きいと、元とは別の「間違った解釈の服」として広まる（[文化の種類](culture-kinds.md)の「言葉の系統」）。
- 流行は、何年かで廃れる（新しい流行に置き換わる、か、元の地域の服に戻る）。

### 絵の作り方（2026-10-14 に決定）
- 実行中に絵を AI で作らない（決定性と描画の重さのため）。
- **パーツの重ね合わせ**: 住人の素体の上に、髪・上着・帽子・飾りのパーツを重ねる。どのパーツを着るかは、上の決まりと乱数で決める。
- **色の差し替え（パレットスワップ）**: 流行の色は、シェーダーで決まった色を差し替えて表す。
- パーツの絵は、事前に用意する。画像生成（ComfyUI など）で作るかは、画像生成のツールのライセンス（[AI による表現](ai-presentation.md)の未決）を確かめてから決める。それまでは手描きか仮の絵。

### 未決だったことの決め方（2026-10-17 に AI の推奨で決め、人間が一覧で確認した）
- **防寒着を着られる条件**: 地域で素材（毛皮・羊毛・綿など）が手に入ること。流行の服も、素材が手に入り、豊かであるときに着られる。
- **絵**: 素体は今の住人の絵（10 × 14 px）のまま。パーツは手描きを基本にする。画像生成を使うときは、予言者の絵と同じく利用規約を確かめ、[credits.md](../credits.md) に記録する。
- **保存**: 住人の服は保存しない（決まりと乱数から毎回作り直す）。地域の流行は保存する。
