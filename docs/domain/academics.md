## 目的

プレイヤーが技術の木を解放するのではなく、住人の好奇心や危機感から学問がひとりでに興り、ときに偽科学や異端審問が暴走する様子を観察できるようにする。

## ゲームのルール

用語は [用語集](glossary.md) に合わせる。この節は案を写したもので、値も規則もまだ決めていない。

### 知の蓄え（2026-10-15 に決定）
- 学問は、発明の木と別の値（[発明の木](invention-tree.md)）として、地域ごとの**知の蓄え**で持つ。
- 学者の人数（[人の数](population.md)のまとまりの職業・名のある学者）と、記録の手段（文字・書物・印刷の発明）で溜まる。
- 蓄えが発明の前提になり、[信仰と世俗化](secularization.md)の「学問で信仰が薄れる」に効く。
- 学者がいなくなり、記録が失われると減る（現実のアレクサンドリア図書館、西ローマ帝国の崩壊後の知識の喪失）。
- 道の網（[運送と物流](logistics.md)）で、隣の地域へ少しずつ伝わる。
- 下の「4 つの段階」は、蓄えの量と記録の発明から付ける名札として読む。

### 起こり方・分野・異端審問・古い知（2026-10-16 に決定）
下の案（自己実現の高い住人から起こる・五行の 5 分野の蓄え・不穏での処刑・設計図で一夜の産業革命）を、上の「知の蓄え」に合わせて読み替える。
- **学問は、食料の余り・都市・記録の発明で起こる**: 食料に余裕があり（[食料の生産](food-production.md)）、大きな集落（都市。[国と集落](polity.md)）があり、文字など記録の発明（[発明の木](invention-tree.md)）を知る地域で、学者のまとまりが生まれ、蓄えが溜まり始める（アテネ・バグダードの知恵の館）。危機（疫病・氾濫など）は、その問題に関わる分野の発明を少し速める。今の住人の「工房で研究する」は、名のある学者の暮らしとして残す。
- **蓄えは 1 つ、分野は名札**: 知の蓄えは地域に 1 つ。どの分野が育っているかは、その地域が知っている発明の偏りから付ける名札にする（医学の発明が多ければ「医学の都」）。分野の効き目は、その分野の発明が生まれやすくなることで出す。下の五行の 5 分野の表は、名札の表として使う（分野は、知が増えるにつれて分かれてきた）。
- **異端審問は、教えの中身で決まる**: 「知の禁忌」の教えの信者が多い地域では、蓄えが溜まりにくく、学者が裁かれることがある（年表の文。ガリレオ裁判）。「知の崇拝」の教えなら、学問が進む（イスラームの黄金時代・修道院の写本）。信仰の強さや不穏の高さだけでは決めない。2026-10-16 に、記号「知」の禁忌・崇拝にすると決めた（[信仰としてのドグマ](dogma-belief.md)）。
- **古い知は、失った発明を取り戻しやすくする**: 地層の遺物（[地層](strata.md)）に、その時代に知られていた発明を記録する。蓄えの高い地域が掘り当てると、その発明が生まれやすくなる（前提を満たせば。ルネサンスの古典の再発見、アンティキティラ島の機械）。前提を飛ばして一夜で産業革命が起きることはしない。

### 学問の起こり方（案）
- 空腹（L1）・住居（L2）が満たされた住人のうち、自己実現（L5。案では「知的好奇心」）の高い人がいる地域や、疫病・氾濫などの危機に直面した地域で、学問がひとりでに起こる。

### 学問の 4 つの段階（案）

| 段階 | 施設（案） | 起きること（案） |
| :--- | :--- | :--- |
| 第 1 期: 口伝と神話 | 焚き火・祠 | 自然の出来事や神託を「神の気まぐれ」として、詩や昔話で覚える |
| 第 2 期: 書院と観察 | 書院・図書館 | 本草学（薬草）・農学（肥料）など、暮らしに役立つ学問が育つ。学者（`Scholar`）の職業ができる |
| 第 3 期: 大学と学会 | 大学・天体観測所 | 物理学・天文学・経済学が分かれ、論文が出て、地域の技術と文化が大きく伸びる |
| 第 4 期: 考古学 | 発掘研究所 | 地下の層を調べ、前の周回で滅びた自分たちの文明を、場違いな遺物（オーパーツ）として解き明かし始める（[地層](strata.md)） |

### 五行の 5 つの分野（案）
- 地域でどの分野が育つかは、下されたルーンと、まわりの環境（五行の偏り）から、シードを指定した乱数で決まる。

| 分野 | 五行 | 調べるもの | 成果（案） | 危うさ（案） |
| :--- | :--- | :--- | :--- | :--- |
| 本草学・医学（`Medicine`） | 木（`SYM_TREE`） | 薬草・人体・病のしくみ | 疫病で死ぬ人が減り、寿命が延びる | 人体実験で SAN 値が下がる |
| 天文学・神学（`Theology`） | 火（`SYM_FIRE`） | 星の巡り・神託の読み解き・暦 | 暦で農耕がはかどり、神威が増える | 天動説・邪教が生まれる |
| 地質学・農学（`Geology`） | 土（`SYM_EARTH`） | 土・地層・地震・鉱物 | 農地の生産が大きく上がり、遺物を掘り当てやすくなり、建物が丈夫になる | |
| 博物学・機械学（`Engineering`） | 金（`SYM_METAL`） | 力学・製鉄・蒸気・電気 | 工場・鉄道がはかどり、大気の汚れを読み解く | |
| 水文学・海洋学（`Hydrology`） | 水（`SYM_WATER`） | 流れ・治水・深海の生き物 | 治水が必ず成功し、海底人への変わり方が解き明かされて進む | |

- 案の「木（WOOD）」は、記号の ID `SYM_TREE` に読み替える。

### 二次誤解と社会のドラマ（案）
- **異端審問と学者の処刑**: カオス度が高く宗教の強い地域で、学者が真理を見つけると、「神の教えに背く異端」として火あぶりにされる。研究が数十年止まる。
- **論文の誤訳と偽科学**: SAN 値の低い学者が書いた歪んだ論文が学会に通ると、「穢れ（`SYM_BLOOD`）を体に入れれば不死になる」のような偽科学のカルトができ、地域で人体実験が始まる。
- **古い論文の発掘（オーパーツ）**: 都市が滅びて地下に沈んだ数百年後、未来の学者が地下から昔の蒸気機関の設計図（前のプレイの遺物）を掘り当て、未開の村で一夜にして産業革命が起きる。

### データの案（MVP）
- 地域ごと: 5 つの分野の研究のたまり（0〜100）・いちばん論文の出ている分野（`DominantField`）。
- 研究による倍率 ＝ 1.0 ＋ その分野のたまり × 0.01。

### 先に要るもの
- 学問の建物（書院・図書館・大学・天体観測所・発掘研究所）。今の建物は工房・祠・家だけ。
- 学者の職業（[住人の職業](resident-roles.md)）。
- 効き目の相手: 疫病（[疫病](plague.md)）、寿命（老衰の規則）、農地（[食料の生産](food-production.md)）、遺物の発掘（[地層](strata.md)）、工場・鉄道、治水（[治水と水利](water-control.md)）、海底人（構想「異人種と海中都市」）。

### 規則
- 学問が起こる食料の余り・都市の大きさ・記録の発明の条件の値と、段階の進み方の値。分野の名札の付け方（発明の偏りの測り方）。
- 遺物に記録する発明の数と、取り戻しやすさの量。
- 研究のたまり方・減り方（異端審問で止まる年数など）。
- 分野ごとの効き目の量と、倍率の使い道。

### 保存と画面
