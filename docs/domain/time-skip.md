- テスト仕様書: [docs/test/time-skip.md](../test/time-skip.md)

## 目的

ドグマが数十〜数百年かけて星の環境をどう偏らせるかを計算する。プレイヤーが改ざんの結果を観察する場面となる。

## ゲームのルール

用語は [用語集](glossary.md) に合わせる。

- 星がすでに崩壊しているときは、何も変えずに終わる。
- 指定された年数だけ、1年ずつ世界の状態を進める。1年ごとに、次の順で処理する。
  1. 年を1つ進め、登録されている全ドグマの変化量（下の表の量 × ドグマの強度）を足し合わせて加える。
  2. 各値を下の範囲に収める（クランプ）。
  3. 崩壊の条件を判定する。崩壊したら、その年の値のまま跳躍を中断する。
- 表に無い組み合わせ（例: 火の崇拝、血の禁忌）のドグマは、環境を変えない。
- ドグマは減衰も消滅もせず、以降の跳躍でも同じ強度で効き続ける。
- MVP では、ドグマ以外の要因で環境は変わらない（環境どうしの連鎖は入れない）。

### 1年あたりの環境の変化（× 強度）

値は [`game/data/rules.json`](../../game/data/rules.json) の `world.dogmaEffects` にある（`perYear` に書いていない項目は 0）。変化量を持つ組み合わせと、その意味は次のとおり。

| 対象の記号 | 種別 | 変える項目 |
| :--- | :--- | :--- |
| `SYM_TREE` | 禁忌（伐採禁止） | 森林量、水資源 |
| `SYM_TREE` | 崇拝（植林） | 森林量、調和度 |
| `SYM_TREE` | 破壊（焼き払い） | 森林量、カオス度 |
| `SYM_WATER` | 禁忌（祈祷拒否） | 水資源、気温 |
| `SYM_WATER` | 崇拝（治水） | 水資源、気温 |
| `SYM_WATER` | 破壊（水質汚染） | 水資源、カオス度 |
| `SYM_FIRE` | 禁忌（火の封印） | 気温 |
| `SYM_FIRE` | 破壊（焦土作戦） | 森林量、気温、カオス度 |
| `SYM_BLOOD` | 崇拝（生贄） | カオス度、調和度 |
| `SYM_BLOOD` | 破壊（戦争） | カオス度、調和度 |

### 世界の状態の範囲と初期値

範囲は `world.min`・`world.max`、初期値は `world.initial` にある。

| 項目 | コード上の名前 |
| :--- | :--- |
| 森林量 | `ForestAmount` |
| 水資源 | `WaterAmount` |
| 気温（℃） | `Temperature` |
| カオス度 | `ChaosLevel` |
| 調和度 | `HarmonyLevel` |

### カオス度の自然な減少

- カオス度は、ドグマが無くても毎年 `world.chaosDecayPerYear`（0.2）ずつ下がる。ドグマの効果で上がる分と合算してから、0（下限）を下回らないようにする（2026-10-13 に決定。値はゲームのデータ定義 `rules.json` のもの）。
- ドグマで上げたカオス度が、ドグマを止めたあとに少しずつ消えるようにするため。住人の SAN 値はカオス度で減る（[人の欲求と健康](agent-needs.md)）ので、カオス度が下がらないと住人が崩れ続けた。
- 受け入れ条件 AC-time-skip-001〜010 は、この減少を 0 とした定義で計算している。減少を入れた定義は AC-time-skip-011〜013。

### 星の崩壊

次のどれかを満たした時点で、星は崩壊する（`IsDestroyed` が true）。閾値は `world.collapse` にある。

1. カオス度が `chaosAtOrAbove` 以上
2. 水資源が `barrenWaterAtOrBelow` 以下、かつ森林量が `barrenForestAtOrBelow` 以下（不毛）
3. 気温が `temperatureAtOrAbove` 以上、または `temperatureAtOrBelow` 以下

## 対象外

- 環境どうしの連鎖（例: 水資源が 50 未満なら気温とカオス度が上がる。`memo/archtecture.md` の案）: MVP には入れない。後で検討する。
- ドグマの感染・固着、時代（Epoch）の推移、地層: MVP の範囲外。
