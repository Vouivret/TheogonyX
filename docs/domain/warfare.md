## 目的

神（プレイヤー）のドグマと人の欲求から、地域どうしの対立が勝手に生まれ、戦争・略奪・廃墟化を経て、勝者が敗者の廃墟の上に建て増し、歴史を書き換える様子を見せる。地層の「重ね建て」と「二次誤解」に、戦争という大きなきっかけを与える。

## ゲームのルール

用語は [用語集](glossary.md) に合わせる。指示書の内容を写したもので、数値・条件の多くは「未決」にある。

### 決定性の境界
- 関係の変化・宣戦・進軍・戦闘の勝敗・占領・廃墟化は、すべてコアがシードを指定した乱数（`System.Random`）で決める。同じシード・同じ入力からは同じ結果になる。
- 部隊の ID は通し番号で振る（`Guid.NewGuid()` を使わない）。座標はコアで定義した型を使い、Godot の型（`Vector2` など）を使わない。
- 地域の数はコードに直書きせず、`RegionMap`（[文明の創発的な発展](emergent-progression.md)）から取る。閾値・戦闘力の重みは `rules.json` に置く。
- 勝者の学者 AI（LLM）が書く歴史は、表現だけにする。二次誤解の中身はコアが決め、AI はそれを語る（[地層](strata.md)の「発掘と二次誤解」、[AI による表現](ai-presentation.md)の決定性の境界）。
- 同じシードで、戦争の発生・戦闘の結果・占領と廃墟化が毎回同じになることを、自動テストで保証する。

### 戦争が生まれる 4 つの動機
| 動機 | 内容 |
| :--- | :--- |
| 資源・土地の奪い合い | 食料・水の足りない地域が、豊かな隣の地域へ攻め込む（欲求の L1・L2 が崩れる） |
| ドグマの対立（聖戦） | 例: 太陽を崇める地域 と 深海を崇める地域。互いのドグマを邪教とみなし、相手の神殿を焼きに行く |
| 種族の覇権争い | 陸の人 と 海底人（半魚人）。水辺の権益・沿岸の都市の支配を巡る |
| 個人の愛憎 | SAN 値が 0 になった指導者が、自分を振った相手や恋敵のいる地域へ、私怨で全軍を進ませる |

### 戦争の 4 つの段階
1. **外交の緊張**: 地域どうしの関係（−1.0 宿敵 〜 1.0 同盟）が、ドグマの不一致・資源の不足・指導者の暴走で悪くなる。スマホ（コンパニオン）に、暗黒議会から「〇〇への宣戦布告を提案します」という知らせが届く。
2. **進軍と衝突**: 宣戦すると、攻める地域から部隊（指示書の `MilitaryUnitGroup`。発祥の地域・攻める先の地域・兵の数・戦闘力）が生まれ、ポテンシャルフィールドに沿って攻める先の地域の 2 列へ進む。
   - 戦闘力は、地域の技術（兵器の質）と文化（士気・信仰）の重みつき平均で決める。技術が高い地域は鉄の甲冑・銃・機械兵で、文化が高い地域は狂信の士気・聖歌・召喚獣で押す。
   - 中拡大の視点: 数百〜数千の点が隊列を組んで隣の地域へ進む。詳細の視点: 32 px の兵士・投石機・魔法・蒸気兵器が入り乱れて戦う（[カメラの視点](camera-views.md)）。
3. **決着・略奪・廃墟化**: 負けた地域の建物の一部が壊れ、火と煙とともに廃墟（土台）になる（[地層](strata.md)の「廃墟化と建て増し」）。生き残った人は奴隷にされるか、地下へ逃げて地底人になる。
4. **勝者の建て増しと歴史の書き換え**: 勝った地域が、壊した神殿の廃墟の上に、自分たちの文明の値に合った建物を建て増す。勝者の学者が、勝者に都合のよい歴史を書く（例: 「負けた古代人は、我が神の奴隷となるためにこの土台を作ったのだ」）。

### 関係の状態（状態遷移表の案）
- 地域の組ごとに、同盟（`Alliance`）・平和（`Peace`）・緊張（`Tension`）・戦争（`AtWar`）のどれかの状態を持つ。
- 指示書に書かれている遷移は「関係が −0.8 を下回ったら戦争」だけである。下の表の「未決」は、遷移できるか・きっかけは何かがまだ決まっていない。決まったら、コードの 1 か所の表と 1 対 1 で対応させ、「不可」の遷移はエラーにする。

| 今の状態 ＼ きっかけ | 関係が −0.8 を下回る | 戦争が決着する | 関係がよくなる | 関係が悪くなる（−0.8 より上） |
| :--- | :--- | :--- | :--- | :--- |
| 同盟 | 戦争（指示書） | — | 未決 | 未決 |
| 平和 | 戦争（指示書） | — | 未決 | 未決 |
| 緊張 | 戦争（指示書） | — | 未決 | 未決 |
| 戦争 | 未決 | 未決 | 未決 | 未決 |

### 近代の戦争の規模（2026-10-15 に検討）
- **核（2026-10-15 に決定）**: 入れるが、使われにくくする。
  - [発明の木](invention-tree.md)の近代の先に、核を置く。
  - 核を持つ地域は、主に抑止の力として持つ（持っている相手には攻め込みにくくなる）。使うのは、極めてまれにする（例: SAN 値が 0 になって狂乱した指導者・滅びかけた地域。条件は未決）。
  - 使われたとき（案）: その地域は廃墟になり、人が大きく減る。すすが日差しを遮って星全体が数年冷える（核の冬。[温暖化と気候の長い変化](greenhouse.md)の火山の冬と同じ仕組み）。飢饉が重なって人が絶えれば星の崩壊になるが、特別な滅び方は置かない（[星の崩壊と文明の崩壊](collapse.md)）。
- **兵と死者**: 人のまとまり（[人の数](population.md)）とどうつなぐかは、別に考える（2026-10-15）。
- **戦闘力（仮置き。好みの指定なし）**: 兵の数 × 武器の発明（[発明の木](invention-tree.md)。銅の剣 → 鉄 → 火薬 → 機関銃 → 飛行機）× 士気（信仰の強さ・聖戦か）とし、地形（山・川・海）も効く案にしておく。今の「技術と文化の値の重み付き平均」を置き換える。
- **描写（仮置き。好みの指定なし）**: 引いて見ると点と煙、詳細の視点ではドット絵の小さな兵が戦い、倒れる程度にする。血や残虐な絵は出さず、虐殺・奴隷は年表の文だけで語る案にしておく。
- **世界大戦**: 同盟が連鎖して多くの地域が参戦すれば、決まりを足さなくても起きる（案）。

## 未決

### 指示書の中での食い違い
- **戦争に入る条件**: 文章は「−0.8 を下回ったら、乱数の判定を経て戦争」、コード例は「−0.8 を下回ったらすぐ戦争」。
- **関係の向き**: 関係の値は向きつき（A から B と B から A が別）だが、戦争の状態は両方向まとめて変わる。片方だけが嫌っているときの扱い。
- **状態の移り方**: 上の状態遷移表の「未決」。和平・同盟・緊張への移り方と、戦争の終わり方（どちらかの兵がいなくなる・年数・乱数）。

### 前提になる仕組み
- **地域と国**: 1 つの地域を 1 つの国にするか、国が複数の地域を持つか（占領で領土が広がる）。
- **攻め込める先**: 地域は東西に 1 列に並び、計算上は東西の端がつながっていない（[カメラの視点](camera-views.md)）。隣の地域だけか、遠くの地域へも進めるか。
- **兵の数**: [群衆](crowd.md)は見た目だけで、人口のモデルが無い。兵力をどこから決めるか（[人の欲求と健康](agent-needs.md)の「群衆との関係」と一緒に決める）。
- **スマホの提案**: プレイヤーが宣戦を許可・却下できるなら、プレイヤーの新しい操作になり、[messages.md](../protocol/messages.md) を変える。ただの知らせなら表示だけ。
- **先に要るもの**:
  - 食料・水の不足: 森林量・水資源は星全体で 1 つずつで、地域ごとの資源が無い（[文明の創発的な発展](emergent-progression.md)の「1 年ごとの計算」）。
  - 太陽・深海のドグマ: 記号は木・雨・血・火の 4 つだけ（[文明の創発的な発展](emergent-progression.md)の未決「記号を足すか」）。
  - 陸の人と海底人: ロードマップの構想「異人種と海中都市」。
  - SAN 値が 0 の指導者・恋敵: [人の欲求と健康](agent-needs.md)。
  - 詳細の視点の兵士・投石機・兵器の絵。

### 規則と値
- 関係の初期値と、ドグマの不一致・資源の不足・指導者の暴走で関係が変わる量。
- 戦闘力の重み（技術と文化）、兵の数の決め方、戦闘の勝敗の決め方と乱数の使い方。
- 負けた地域で廃墟になる建物の割合・選び方、建て増す建物の決め方。
- 奴隷にされる・地底人になる人の扱い（人のモデルができてから）。
