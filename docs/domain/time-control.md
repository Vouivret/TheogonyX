# 仕様書: 時間の進め方（跳躍ボタン・自動進行・リセット）

- テスト仕様書: [docs/test/time-control.md](../test/time-control.md)
- 関連ADR: なし
- 通信: なし
- 画面デザイン: なし
- 出典: 2026-10-11 のチャットでの確定仕様（ロードマップ M1「画面の視覚化」）

## 目的

神（プレイヤー）が、星の時間を一気に進めて結果を見ることと、少しずつ進めて変化を眺めることの両方をできるようにする。

## ゲームのルール

用語は [用語集](glossary.md) に合わせる。年の計算そのものは [時代跳躍](time-skip.md) に従う。

2026-10-15 に、自動進行の速さに、出来事の多さで決まる倍率を掛けると決めた（[歴史の長さと時間の速さ](time-scale.md)。まだ作っていない）。

- **100年跳躍ボタン**: 押すと 100 年分の時代跳躍を一度に計算し、終わった後の状態で画面を更新する。途中の年は描画しない。途中で星が崩壊したら、その年で止まる（時代跳躍の仕様どおり）。自動進行中でも押せ、押した後も自動進行は続く。
- **自動進行**: オンにすると、1年ずつ時代跳躍し、そのたびに画面を更新する。速さは次の3段階で、切り替えボタンを押すたびに「通常 → 高速 → 現実同期 → 通常」と回す。
  - 通常（既定）: 1秒に1年
  - 高速: 1秒に10年（0.1秒ごとに1年）
  - 現実同期: 現実の24時間で1年（1 年の秒数は [`game/data/rules.json`](../../game/data/rules.json) に置く）。自動進行中は、HUD に次の年までの残り時間（`hh:mm:ss`）を出す。
- その年の進み（前の年から何秒たったか）は、一時停止しても残り、再開すると続きから数える。速さを切り替えたときと世界再創生では 0 に戻す。進みと選んだ速さはセーブに残す（[save-data.md](save-data.md)）。ゲームを閉じていた間は進まない。
- 1 フレームで進めるのは 1 年まで。
- **一時停止**: 自動進行をオフにする。
- **世界再創生（リセット）**: いつでも押せる。押すと、年を 0、環境を初期値に戻し、ドグマの一覧を空にし、自動進行を止める（起動直後と同じ状態になる）。予言者は新しい夢を見る（[dream-tampering.md](dream-tampering.md)）。星が崩壊しているときは、ボタンを赤く点滅させて目立たせる。
- 星が崩壊したら、自動進行を止める。崩壊した後に押せるのはリセットだけである。
- 予言者が夢を見たときと依頼を出したときも、自動進行を止める（一時停止と同じ遷移）。神託を下すと再開する（[dream-tampering.md](dream-tampering.md)）。

### 状態遷移

| 現在の状態 ＼ きっかけ | 100年跳躍ボタン | 自動進行をオン | 一時停止 | 1年経過（自動進行の間隔） | リセット |
| :--- | :--- | :--- | :--- | :--- | :--- |
| 停止中 | 停止中（100年進める。崩壊したら崩壊） | 自動進行中 | 不可 | 不可 | 停止中（初期化する） |
| 自動進行中 | 自動進行中（100年進める。崩壊したら崩壊） | 不可 | 停止中 | 自動進行中（1年進める。崩壊したら崩壊） | 停止中（初期化する） |
| 崩壊 | 不可 | 不可 | 不可 | 不可 | 停止中（初期化する） |

- 「崩壊したら崩壊」は、跳躍の結果 `IsDestroyed` が true になったときに崩壊の状態へ移ることを表す。
- 「不可」の操作は、ボタンを押せない状態（無効表示）にする。
- 速さの切り替えは状態を変えない（どの状態でも切り替えられ、次に自動進行するときの速さになる）。

## 対象外

- 跳躍する年数を選ぶ機能（50年・300年など）: 確定仕様のボタンは 100 年だけである。

## 未決

なし。（U5〜U8・U10 は 2026-10-11 に解消済み。上のルールに反映した。）
