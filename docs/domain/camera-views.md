## 目的

「星全体を眺める」「群衆がうごめく様子を見る」「ドット絵を細部まで愛でる」の 3 つの視点を、ズームで行き来できるようにする。地球のアクアリウムとして眺める気持ちよさと、シミュレーションの動きの両方を、それぞれに合った見せ方で味わえるようにする。

## ゲームのルール

用語は [用語集](glossary.md) に合わせる。視点の切り替えは見た目だけで、シミュレーションの結果には影響しない。指示書の内容を写したもので、値の多くは「未決」にある。

### 3 つの視点

| 視点 | 目的 | 見せるもの | 効果 |
| :--- | :--- | :--- | :--- |
| 大陸（マクロ） | 星全体の環境の移り変わり・気候・カオス度の広がりを見渡す | 星（大陸）の全景、雲の動き、オーロラ・カオスのオーラ、気候の変化、16 列それぞれの文明の度合いを表す光 | 回転のシェーダー、雲・オーロラ |
| 中拡大（メゾ） | 都市の発展、交易路、群衆の避難・大移動を見る | 16 列の地表、点で描く群衆（数千〜数万人）、都市の広がり、地域ごとの文明の差 | 簡単なライティング、流れ（ポテンシャルフィールド）の見える化 |
| 詳細（ミクロ） | 32 × 32 px のドット絵、人間 1 人ひとりの営み、積み重なった建物の細部を愛でる | 32 px の建物と人間の絵、欲求のアイコン（満腹・信仰・正気度）、建物の構造・足場、焚き火の揺らぎ、地下の地層のちら見せ | 法線マップ、`PointLight2D`、ティルトシフト（[画面の効果](visual-effects.md)） |

### 切り替え
- マウスホイール・タップで、大陸 → 中拡大 → 詳細と、ズームの度合いを滑らかに補間して移る（`Camera2D.Zoom`）。
- ズームの度合いに応じて、描くもの（ノード）と効果（シェーダー）を切り替える。指示書のズームの範囲（目安）は次のとおり。

  | 視点 | `Camera2D.Zoom` |
  | :--- | :--- |
  | 大陸 | 0.1〜0.3 倍 |
  | 中拡大 | 0.4〜1.0 倍 |
  | 詳細 | 1.5〜4.0 倍 |

### 大陸の視点での回転（東西をつなぐ）
- 16 列の地表を、東西の端がつながった輪（ループ）として扱う。
- 大陸の視点では、輪にした地表を回転のシェーダー（`SubViewport` ＋ 2D の星のシェーダー）で星や輪の形の大陸に貼り、ドラッグやキーで回して裏側の地域を見る。
- 東西の端が無くなるので、西から東へ広がったドグマが、一周して東から戻ってくる。

### 群衆の描き方
- 中拡大では、人間を点（1 px・粒子）で描く（今の[群衆](crowd.md)と同じ）。
- 詳細では、人間を 1 人ずつ 32 px の絵で描き、欲求のアイコンを出す。

## 未決

### 今の仕様・コードとの食い違い
- **ピクセルパーフェクト**: 今の画面は 480 × 270 を整数倍に拡大して、ドットの幅をそろえている（[art-guide.md](../art-guide.md)）。0.1〜4.0 倍の小数のズームと、ズームの補間の途中は、ドットの幅がそろわない。詳細の視点だけ整数倍（2 倍・4 倍など）に吸着させるか、ドットの幅の乱れを受け入れるか。
- **ズームの倍率の基準**: 今の地表は 256 × 144 px（16 × 9 のタイル、1 タイル 16 px）で、480 × 270 の画面に収まっている。指示書の倍率が何に対する倍率か（今の見え方を 1.0 とするか）。大陸の 0.1 倍では地表が 26 px ほどになる。
- **東西をつなぐこと**: 今の地表は、環境の異常を「左（西）の列から」塗り（[星の表示](planet-display.md)）、群衆は地表の端で跳ね返る（[群衆](crowd.md)）。輪にするなら、群衆を端で反対側へ回り込ませるか、力の場・群れの集計を端でつなぐか、GPU 版と CPU 版の両方を直すか。異常を西から塗ることは変えないか。大陸の視点の見た目だけを輪にして、中拡大・詳細では今どおり端があるままにする手もある。
- **ドグマが広がる仕組みが無い**: 「西から東へ広がったドグマが一周して戻る」には、ドグマが地域（列）から地域へ広がる仕組みが要る。今のドグマは星全体に効く。[文明の創発的な発展](emergent-progression.md)の未決（ドグマがどの地域に効くか）と一緒に決める。
- **詳細の視点の絵が無い**: 32 px の絵は予言者だけで、建物・人間の絵・欲求は無い（欲求はロードマップの構想「欲求ベースの行動」）。絵が揃うまで詳細の視点で何を見せるか。
- **群衆を 1 人ずつ描くこと**: 群衆は 10,000 人を 1 回の DrawCall で点として描いている（[群衆](crowd.md)）。詳細の視点で画面に入っている人だけを 32 px の絵で描くか。人数の上限。
- **画面の効果との関係**: [画面の効果](visual-effects.md)では、ティルトシフト・法線マップ・焚き火を視点に関係なく出す形で書いている。詳細の視点だけにするなら、visual-effects.md も直す。焚き火（今は常に描いている）を中拡大・大陸で出すか。
- **地層の見せ方**: [地層](strata.md)の地下の断面（ボタンかズームで切り替え）と、詳細の視点の「地下の地層のちら見せ」の関係。

### 規則と値
- 3 つの視点の境目のズームの値と、補間の速さ。視点の境目で描くものを急に切り替えるか、重ねて薄くしながら切り替えるか。
- 起動したときの視点。
- カメラの動かし方（ドラッグで動かす範囲、ズームの中心をマウスの位置にするか）と、キーボードの操作。
- 「タップ」は PC のタッチ画面のことか、スマホ（コンパニオン）からの操作か。
- 大陸の視点の形（球か輪か）、雲・オーロラ・カオスのオーラ・文明の光を何の値から決めるか。
- HUD・夢の欄・QR コードを、視点によって出し分けるか。

### 通信と性能
- スマホへの画面の配信（[frame-stream.md](frame-stream.md)）で、PC と同じ視点を映すか、決まった視点を映すか。
- 大陸の視点の回転のシェーダーと `SubViewport` を足した後も、群衆と合わせて [nfr.md](../nfr.md) の性能の目標を満たすか。

### 用語
- 大陸の視点・中拡大の視点・詳細の視点（マクロ・メゾ・ミクロ）を用語集に足すか。
