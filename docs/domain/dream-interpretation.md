- テスト仕様書: [docs/test/dream-interpretation.md](../test/dream-interpretation.md)
- 関連ADR: なし

## 目的

神（プレイヤー）が改ざんした夢から、予言者がどの因果を読み取り、どんなドグマを形成するかを決める。プレイヤーの介入が歴史に影響する入口となる。

## ゲームのルール

用語は [用語集](glossary.md) に合わせる。

- 夢は夢ノードの並びである。夢ノードは記号と重み（`Weight`、0.0〜1.0）を持つ。
- 隣り合う夢ノードのペアをすべて調べる（夢ノードが N 個なら N−1 組）。
- 夢ノードが0個または1個のときはペアが作れないので、ドグマを生成しない（結果は「ドグマ無し」）。
- ペアの衝撃度（Impact）は次の式で求める。
  - 衝撃度 = 1番目の重み × |1番目の感情の極性| ＋ 2番目の重み × |2番目の感情の極性|
- 衝撃度が最大のペアから、ドグマを1つ生成する。同点のときは、夢の後ろ（未来）にあるペアを選ぶ（直近の夢の記憶ほど強く残るため）。
- ドグマの対象は、ペアの1番目（原因側）の記号である。
- ドグマの種別は、ペアの2つの感情の極性の和で決める。閾値は [`game/data/rules.json`](../../game/data/rules.json) の `dogmaTypeThresholds` にある（禁忌の閾値 < 崇拝の閾値）。

  | 極性の和 | 種別 |
  | :--- | :--- |
  | 禁忌の閾値（`tabooAtOrBelow`）以下 | 禁忌（`Taboo`） |
  | 禁忌の閾値より大きく、崇拝の閾値未満 | 破壊（`Destruction`） |
  | 崇拝の閾値（`worshipAtOrAbove`）以上 | 崇拝（`Worship`） |

- ドグマの強度（`Intensity`）は、衝撃度と 1.0 の小さいほう。
- 予言者の狂信度は、MVP では使わない。

### MVP で使う記号

感情の極性の値は [`game/data/symbols.json`](../../game/data/symbols.json) にある（範囲は −1.0〜+1.0）。

| ID | 名前 | 概要 |
| :--- | :--- | :--- |
| `SYM_TREE` | 木/森林 | 生命・環境 |
| `SYM_RAIN` | 恵みの雨 | 恵み・水資源 |
| `SYM_BLOOD` | 血/死 | 破滅・恐怖 |
| `SYM_FIRE` | 聖なる火 | 文明・エネルギー |

## 受け入れ条件

夢は「記号（重み）」を左から順に並べて書く。

結果の数値は、MVP で決めたデータ定義の値（極性: 木 +0.4、雨 +0.6、血 −0.9、火 +0.1。閾値: 禁忌 −0.3、崇拝 +0.3）で計算している。自動テストはこの値を `tests/` の中に持つので、`game/data/` を調整しても受け入れ条件とテストは変わらない。

| ID | Given（前提） | When（操作） | Then（結果） |
| :--- | :--- | :--- | :--- |
| AC-dream-interpretation-001 | 夢が 木(0.5) → 血(0.9) | 夢を解釈する | 対象 `SYM_TREE`、種別 禁忌、強度 1.0（衝撃度 1.01 を 1.0 に抑える） |
| AC-dream-interpretation-002 | 夢が 雨(1.0) → 血(1.0)（極性の和がちょうど −0.3） | 夢を解釈する | 対象 `SYM_RAIN`、種別 禁忌、強度 1.0 |
| AC-dream-interpretation-003 | 夢が 木(0.5) → 雨(0.5) | 夢を解釈する | 対象 `SYM_TREE`、種別 崇拝、強度 0.5 |
| AC-dream-interpretation-004 | 夢が 火(1.0) → 火(1.0)（極性の和 +0.2） | 夢を解釈する | 対象 `SYM_FIRE`、種別 破壊、強度 0.2 |
| AC-dream-interpretation-005 | 夢が 木(0.5) → 雨(0.5) → 血(1.0) | 夢を解釈する | 衝撃度が最大の 雨→血 が選ばれ、対象 `SYM_RAIN`、種別 禁忌、強度 1.0 |
| AC-dream-interpretation-006 | 夢が 雨(0.5) → 木(0.5) → 雨(0.5)（2組の衝撃度がどちらも 0.5） | 夢を解釈する | 後ろのペア 木→雨 が選ばれ、対象 `SYM_TREE`、種別 崇拝、強度 0.5 |
| AC-dream-interpretation-007 | 夢が空（夢ノード0個） | 夢を解釈する | ドグマ無し |
| AC-dream-interpretation-008 | 夢が 血(1.0) だけ（夢ノード1個） | 夢を解釈する | ドグマ無し |

## 対象外

- 予言者の狂信度、ドグマの感染速度（`spreadRate`）: MVP では使わない（`memo/mvp_init.md` に無いため）。
- 問解（人間からの問い合わせへの返答）: MVP の範囲外（`PROMPT_FOR_CLAUDE.md` の最初のマイルストーンに含まれない）。

## 未決

- 衝撃度が 0 のペアしか無いとき（極性 0 の記号だけの夢）、ドグマを生成するか。MVP の記号には極性 0 が無いので、今は起こらない。
