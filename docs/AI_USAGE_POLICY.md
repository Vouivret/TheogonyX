# AI利用ポリシー

> 個人開発のため、社内規定ではなく開発者本人の方針として書く。

- 責任者: 開発者本人（Vouivret）
- 根拠となる規定: なし（個人開発）

## 使ってよいAIサービス
| サービス | 契約形態 | 入力データが学習に使われないこと | 使ってよい用途 |
| :--- | :--- | :--- | :--- |
| Claude（Claude Code・claude.ai） | 個人契約 | 未確認（アカウントの設定で確認する） | 設計の相談、コード・文書の作成、レビュー |

## 渡してよい情報
| 情報の区分 | 例 | 上の表のAIサービス | その他の外部サービス（Web検索など） |
| :--- | :--- | :--- | :--- |
| 公開情報 | OSSのコード、Godot の公式ドキュメント | 可 | 可 |
| 未公開のゲームの内容 | このリポジトリのコード、設計書、ゲームの仕組み | 可 | 不可 |
| 秘密情報・個人情報 | APIキー、配布サイトの認証情報、プレイヤーの個人情報 | 不可 | 不可 |

## AIが生成したものの扱い
- 生成したコード・文書: 開発者本人がレビューしてから取り込む。配布先（ストア）の規約がAI生成コンテンツの申告を求める場合は、それに従う。
- 生成した画像・音声などのアセットは、使ったサービスの利用規約で商用利用できることを確認してから取り込み、`docs/credits.md` に記録する。
- 成果物にAIを使ったことを記録するか: 記録する（コミットに `Co-Authored-By` を残す）。

## 違反や事故のとき
誤って秘密情報を渡した場合: 該当する鍵・トークンを直ちに無効化し、作り直す。
