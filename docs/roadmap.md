# 開発ロードマップ

MVP のコアループ（夢の改ざん → ドグマ生成 → 時代跳躍。結果はログ出力）ができた後に作るものの順番。2026-10-11 時点の構想であり、仕様ではない。各段階に着手するときに、仕様書（`docs/domain/`）と plan を書いて具体化する。

> 未決・残作業は [open-items.md](open-items.md) にまとめている。

> ここでの「M1〜M4」は開発の順番であり、`.agent/rules/project.md` の「フェーズ（Phase 1〜3）」とは別のものである。フェーズはプロジェクト管理の厳しさを表し、人間が切り替える。

## M1: 画面の視覚化（見た目・鑑賞性の構築） — 完了（2026-10-11）
ログ出力だった世界を、Godot の 2D ノードで画面に描画する。

- **TileMap による地球環境の可視化**: `ForestAmount` や `WaterAmount` の値に応じて、2D マップのタイル（緑、黄色、砂漠、氷河）を動的に書き換える。
- **2D ライティングとドット絵の予言者**: 昼夜の環境光（`CanvasModulate`）と、待機アニメーションをするドット絵の予言者で、「アクアリウムとして眺めて楽しい画面」を作る（[仕様書](domain/ambience.md)）。焚き火の明かりと夜空の星は M4 に回した。
- **データ UI（HUD）**: 画面の隅に、西暦・カオス度・調和度・現在のドグマの一覧を表示する。

## M2: スマホ（コンパニオン）との通信連携 — 完了（2026-10-12）
「手元のスマホが神託端末になる」マルチデバイス体験を作る。

- **Godot 側の WebSocket サーバー**: Godot 4 の `WebSocketPeer` で、PC 上にローカルの WebSocket サーバーを立てる。起動時に、接続用の QR コード（ローカル IP）を画面に表示する。
- **スマホ用の Web 画面（HTML/JS）**: スマホのブラウザで開ける、軽量な1枚の Web ページを作る。PC の画面を映し、カードを選んで夢を改ざんし神託を下すと、WebSocket で Godot に命令が届き、ゲーム内の夢やドグマが書き換わる。予言者の依頼（祈り）の吹き出しもスマホに出る（[夢の改ざん](domain/dream-tampering.md)・[依頼](domain/prophet-request.md)）。問解への返答は M4 の構想に移した。
- **現実同期モード（現実の24時間 = ゲーム内の1年）**: 自動進行の速さの 1 つとして、起動している間、現実の 24 時間でゲーム内の 1 年が進む（[仕様書](domain/time-control.md)）。その年の進みはセーブに残るが、ゲームを閉じている間は時間を進めない。スマホへの通知は作っていない（出典: `memo/time_scale.md`）。
- 着手前に決めること: コンパニオンの技術（`.agent/rules/` に言語のルールを足す）、メッセージの契約（`docs/protocol/messages.md`）、ペアリングの方式（`docs/nfr.md` のセキュリティ）。

## M3: GPU（Compute Shader）による大量 NPC・環境の並列計算 — 完了（2026-10-12）
1人だった予言者の周りに、10,000 人の群衆を置く（[仕様書](domain/crowd.md)）。群衆は見た目だけで、シミュレーションの結果には影響しない。

- **水場（湖）**: 水資源で広がり・干上がり、氷河・焦土に覆われると消える湖のタイルを足した（[星の表示](domain/planet-display.md)）。
- **ポテンシャルフィールドによる集団の移動**: 地表のタイル種別から、人を引き寄せる（水場・緑地）・遠ざける（砂漠・氷河・焦土）力の場を作り、群衆が移住・避難する。夢の改ざん → 環境の変化 → タイルの変化 → 人々の移動、が画面でつながる。
- **狂乱と停止**: カオス度が 50 以上になると、群衆が一斉に聖地（予言者の足元）へ押し寄せる。星が崩壊すると止まる。自動進行中だけ動く。
- **群れの動き（Boids の簡略版）**: マスごとの集計から、周りと向きをそろえ、混み合いすぎず・まばらになりすぎないように流れる。人と人の正確な距離による衝突回避はしない。
- **Compute Shader（GLSL）**: `RenderingDevice` で群衆を GPU で計算し、位置を読み戻して描く。同じ計算の CPU 版をコアに持ち、突き合わせのコマンドで一致を確かめる。GPU が使えない環境では CPU 版で動く。乱数は GPU と共有できるハッシュ関数（[ADR 0004](adr/0004-crowd-counter-based-hash-random.md)）。
- **インスタンシングによる描画**: `MultiMeshInstance2D` で、1〜2 px の点の群衆を 1 回の DrawCall で描く。人の形のドット絵・多種族は作っていない。
- 計測: 10,000 人で GPU 版 約 1,000 fps（垂直同期なし）。100,000 人でも GPU 版は 60fps を大きく上回る（[実施記録](test/results/2026-10-12-feat-m3-crowd-gpu.md)）。
- 環境（気候・マグマなど）の格子の並列計算は作っていない。

## M4: コンテンツ・神話世界の深掘り
ゲームの枠組みができた後に、世界観を広げる。

- **文明の創発的な発展**: 固定の時代（原始 → 中世 → …）の代わりに、地域ごとの技術・文化・カオスの連続値と、ドグマの誤解から生まれる変種技術・暗黒議会の極秘研究・自滅と飛躍で、予想できない方向へ文明が育つ（[仕様書の下書き](domain/emergent-progression.md)。2026-10-12 に「時代の推移（Epoch）の演出」から置き換えた）。
- **イベント**: 隕石の衝突、宇宙人の襲来、太古の地底人との接触などのきっかけを追加する。
- **音響・演出**: 星が壊れるときの地鳴り、神聖な BGM、ドット絵のパーティクルエフェクト。
- **焚き火の明かりと夜空の星**: `PointLight2D` による焚き火の明かりと、夜に見える星（M1 から移した）。
- 作る順番（2026-10-12 に決定）:
  - **Must（これが無いと始まらない）**: カメラ（スクロールとズーム）、地表の 512 × 288 px への拡張と 16 地域の計算、Top-Down 3/4 の描画のレイヤー（Y ソート）。Must は 2026-10-13 までにすべてできた（Y ソートのレイヤーは、今は予言者と焚き火だけ）。
  - **M4 の残りの順番（2026-10-13 に決定）**:
    1. カメラの WASD キーでの移動（できた）
    2. 文明の値（技術・文化）と簡単な自律建築（値が閾値を越えたら 32 px の建物が建つ）。仮の値でできた（2026-10-13）。値は画面で見ながら調整する
    3. 法線マップと足元の落ち影（[画面の効果](domain/visual-effects.md)。予言者から始め、建物の絵ができたら建物にも）。予言者と建物に、仮の値でできた（2026-10-13）
    4. 廃墟化・重ね建て・地層沈下（[地層](domain/strata.md)）。老朽化・建て増し・ミクロ沈下・世界再創生での沈下・地下の表示が、仮の値でできた（2026-10-13）。発掘・二次誤解・マクロ沈下は後に回した
    5. AI による表現（LLM・ComfyUI の非同期の演出）。M4 ではやらず、M5 以降に回した（2026-10-13 に決定）。着手するときは、前提の少ない「予言者の誤解」（神託の文。ローカルの LLM）から始める。理由は [AI による表現](domain/ai-presentation.md)の「着手の時期」
    6. 人の欲求と健康は、[仕様の未決](domain/agent-needs.md)を決めるだけにし、コードは M5 で書く（使う所の無いフィールドを先に作らない）
  - **Could（余裕ができたら・M5 以降）**: 異人種と海中都市（水面を透かすシェーダーを含む）、資材を運ぶ複雑なアニメーション（構想「自律建築」）。
  - 上に無い項目（イベント・音響・画面の効果・問解など）の順番は、着手するときに決める。
- **3 段階のカメラの視点**: 大陸（星全体を回して見渡す）・中拡大（点の群衆がうごめく）・詳細（32px のドット絵と光を愛でる）を、ズームで滑らかに行き来する（[仕様書の下書き](domain/camera-views.md)。出典: 2026-10-12 のチャットでの指示）。
- **画面の効果**: `DirectionalLight2D` と法線マップによる陰影、焚き火・ルーンの揺らぐ明かり、ティルトシフトとグロー、水面の反射と屈折、環境の粒子（木漏れ日・灰・胞子・雨）（[仕様書の下書き](domain/visual-effects.md)。出典: 2026-10-12 のチャットでの指示）。
- **構想: 問解**: 人間からの神への問い合わせに、記号カードで返答する（M2 から移した。出典: `memo/game_design_document.md`）。今は、困ったときに予言者が出す[依頼（祈り）](domain/prophet-request.md)が「人間からの神への問い」を担っているので、作るかどうかから決める。
- **構想: AI による表現（LLM・画像生成）**: ローカルの LLM と画像生成で、予言者の誤解・暗黒議会・歴史の神話化・聖遺物 LoRA の演出と、地表に置く 32×32px のドット絵（DB16 のパレット）を作る。ゲームの計算はコアが決定的に行い、AI は表現だけを担う。M3 の後に着手する（[仕様書の下書き](domain/ai-presentation.md)。出典: `memo/add_llm.md`）。
- **構想: 欲求ベースの行動**: 人間にマズローの 5 段階の欲求（空腹・睡眠・住居・交流・承認・自己実現）と肉体・精神の健康（体力・SAN 値・精神崩壊）を持たせ、1 日の生活（労働・休憩・祈り・眠り）と、ドグマによる生活の崩れ（逃げ惑う・祈り狂う・争う）を見せる。家・農地・神殿などの場所が先に要る。欲求で起きる出来事をシミュレーションの結果に影響させるなら、コアで決定的に計算する（M3 の群衆は見た目だけ）。2026-10-13 の 2 つの指示書（欲求とタスク、マズローの 5 段階の欲求と肉体・精神の健康）を[仕様書の下書き](domain/agent-needs.md)にまとめた。M4 の Should の後、建物ができてから着手する。
- **構想: 世代交代と教義の変質**: 人が生まれ、老いて死に、ドグマが言い伝え・風習へと変わりながら次の世代に受け継がれる。ドグマのモデルを変えるので、AI 連携の「歴史の神話化」と一緒に決める。求愛・つがい・子供への性質の引き継ぎ・恋愛のもつれ・異なる種族の間の子供は、2026-10-13 の指示書を[人の欲求と健康の下書き](domain/agent-needs.md)の「つがいと世代交代」にまとめた。
- **構想: 自律建築**: 人間が資材を集め、工事現場（足場・骨組み）を経て建物を完成させ、人口に応じて集落が広がる（道路・家・井戸・風車・柵）。着手前に、資材の獲得で環境の値（森林量・水資源）を減らすか、地表の大きさ（今は 512 × 288 px）・建物の格子（32 px）・カメラ（ズーム）をどうするかを決める。
- **構想: 変貌する建築**: 環境（水没 → 高床式の水上都市、極寒 → イグルー・地下遺構）とドグマ（カオス度が高い → 犠牲壇・塔・トーテム、`Destruction` → 工場・砦）で、建てる建物の種類が変わる。
- **構想: 地域間の戦争**: 資源の奪い合い・ドグマの対立（聖戦）・種族の覇権争い・指導者の愛憎から地域どうしの関係が悪くなり、宣戦 → 進軍と衝突 → 略奪と廃墟化 → 勝者の建て増しと歴史の書き換え と進む。負けた地域の廃墟は[地層](domain/strata.md)の重ね建てと二次誤解につながる（[仕様書の下書き](domain/warfare.md)。出典: 2026-10-13 のチャットでの指示書）。人の欲求と健康の後に着手する。
- **構想: 異人種と海中都市**: 環境（水資源・気温・カオス度）とドグマの組み合わせで、人間が海底人・地底人・樹人・珪素生命・獣人などへ変わる。海底人は水の中に、技術と文化の値に応じた都市（光るサンゴの神殿・貝殻の家 〜 ガラスのドーム・深海の地熱発電）を建て、洪水で沈んだ陸の都市の廃墟の上にも建て増す。水面を透かして海中の都市を見せ、陸と海の種族の交易・信仰の対立・戦争を起こす（出典: 2026-10-12 のチャットでの提案「⑨ 異人種変異 ＆ 海中都市システム」）。建物と文明の値ができてから仕様書にする。着手前に決めること:
  - 種族の変わり方: 群衆は見た目だけなので、種族はコアが地域ごとに決定的に決める（例: 地域の主な種族）。
  - 海: 今は決まったマスに広がる湖だけで、水資源は星全体で 1 つ。海の列や地域ごとの水をどう作るか（[星の表示](domain/planet-display.md)）。
  - 記号: 水・海・深海・変異の記号は無い（[文明の創発的な発展](domain/emergent-progression.md)の「記号を足すか」と一緒に決める）。
  - 水の上の建物: 「水場の上には建てない」（[文明の創発的な発展](domain/emergent-progression.md)）の、海底人の地域での例外。
  - 水面のシェーダー: [画面の効果](domain/visual-effects.md)の水面の反射・屈折との関係。
  - 獣人など、どの種族が・どんな条件で生まれるか（ゲームのルールなので人間が決める）。
- **構想: 地層重ね建て**: 滅びた文明の廃墟（土台・石垣・倒れた柱）を地上に残し、後の人間がその上に建て増す積層都市にする。廃墟は放置されると風化で、大災害では一斉に地下へ沈み、埋もれた瞬間の文明の値（技術・文化・カオス）を残す。掘り当てた人間は、自分たちとの違いから誤解して新しいドグマを生む（[仕様書の下書き](domain/strata.md)）。今の崩壊は世界再創生ですべて初期値に戻すので、周回の終わりの扱い（[AI 連携の未決](domain/ai-presentation.md)）と一緒に決める。
- **構想: 象徴的な建造物の画像生成**: 神殿・モニュメントを建て始めるときに、その時のドグマの属性を画像生成（ComfyUI）に渡し、固有の 32 × 32 px の建物の絵を作る。基本の建物（家・柵・畑・井戸）は用意した絵を使う。生成が失敗・遅延したときの既定の絵と、画像生成のライセンスは AI 連携の未決と一緒に決める。
- 出典（上の 5 つ）: 2026-10-12 のチャットでの提案。M3 から外して M4 の構想にした。
- **構想: 1年より細かい時間の流れ**（出典: `memo/time_scale.md`。今のコアは1年単位で計算している）
  - 完全リアルタイム（1秒 = 1秒）: 予言者の呼吸、焚き火のゆらめき、人間の1日の生活（朝〜夜）が現実の時間と同期する。
  - じっくり観察（12秒 = 1年、1秒 = 1か月）: 緑が少しずつ枯れて砂漠になっていく様子を目で追える速さ。年と年の間の見た目を補う仕組みが要る。

## M5 以降: 自然・経済・神の手・歴史の鑑賞
M4 の後に作る候補（出典: 2026-10-13 のチャットでの提案）。順番と、M4 の構想との入れ替えは、M4 を閉じるときに決める。どれも、計算はコアがシードを指定した乱数で決定的に行い、AI は表現だけを担う。

- **構想: 生態系と季節・気候**: 自然が自分で生きている感覚を強める。
  - 動植物と食物連鎖: 森林に鹿や危険な原生生物が住み、人間が狩り、家畜にする（牧畜）。焦土やカオス度の高い地域には異形のモンスターが自然に湧き、集落を脅かす。
  - 季節（春夏秋冬）と異常気象: 冬は作物が育たず、線路が雪で埋もれて電車が遅れる・止まる（食料と暖房の薪を蓄える必要がある）。寒波・干ばつ・毒霧・オーロラが 16 地域を巡る。
  - 着手前に決めること: 計算の 1 回（Tick）は 1 年なので、季節には 1 年より細かい時間が要る（構想「1年より細かい時間の流れ」）。今の気温・森林量・水資源は星全体で 1 つずつで、地域ごとの気候が無い。動物・モンスターを群衆と同じく見た目だけにするか、結果に影響させるか（[人の欲求と健康](domain/agent-needs.md)の「群衆との関係」）。モンスターと M4 の「イベント」・[文明の発展](domain/emergent-progression.md)の「カオス度によるイベント」との関係。
- **構想: 特産品と経済**: 交通の価値を高める。
  - 地域ごとの特産品: 西の山岳 → 鉄・鉱石、中央の平野 → 小麦・肉、東の沿岸・海中 → 魚・真珠・塩。
  - 自動の交易と値動き: 鉄道・道路でつながった地域どうしに市場ができ、商人が特産品を売り買いする。補給が切れると食料の値段が上がり、貧しい人が暴動を起こす。
  - 着手前に決めること: 鉄道・道路・電車は、今の仕様にもロードマップにも無い（M4 の構想「自律建築」の道路だけ）。先に交通の仕様が要る。今の地表は異常（氷河・焦土・砂漠・密林）が西から列ごとに広がる形で、山岳・平野・沿岸の地形と海が無い（構想「異人種と海中都市」の「海」と一緒に決める）。食料・資源のモデル（[人の欲求と健康](domain/agent-needs.md)・[地域間の戦争](domain/warfare.md)の「先に要るもの」と同じ）。
- **構想: 神の直接の介入（奇跡）**: 夢の改ざん（ドグマ）のほかに、神が直接手を下す。
  - 信仰の還元: 人が祈ると、神（プレイヤー）に信仰のポイントがたまる。
  - 奇跡: ポイントを使って、慈愛の雨・局所的な雷・隕石・豊作などをマップに直接落とす。奇跡を見た人の狂信とカオス度がさらに上がる。
  - 着手前に決めること: プレイヤーの操作が「予言者の夢の改ざんだけ」から増え、コアループが変わる（予言者が誤解して伝えるという今の面白さとの関係）。スマホからも使えるなら、通信の契約（[messages.md](protocol/messages.md)）を変える。隕石と M4 の「イベント」の隕石との関係。ポイントの量・奇跡の効果・場所の選び方（どの地域・どのマスか）。
- **構想: 歴史の全書と博物館（年表の画面）**: アクアリウムとして、過去の歴史や愛憎劇を鑑賞する図鑑。
  - 年表: 「〇〇年: アルトリウスが狂乱し、第一次陸海戦争が始まる」のような歴史が自動で積み重なる。
